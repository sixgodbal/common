# 配置表与导表（Xls）

## 配置表工程

- 配置表目录：`D:\sixgod\gitproject\test\Xls`
- Excel 源表：`D:\sixgod\gitproject\test\Xls\xls`
- 导表工具：`ExcelExporter.py`、`trans.py`、`exporter_cli.py`
- 导出配置：`config/config.json`、`path.json`
- 协议定义：`Definition.proto`、`KVDefinition.proto`

## 一键导表

修改 `xls/` 下的 Excel 后运行：

```
run.bat
```

导出的数据一般会生成到：

- `output/bytes`：游戏内二进制
- `output/cs`：C# 配置类
- `output/json`：可视化调试用 JSON

客户端实际使用的二进制通常路径覆盖到：

- `Demo/Assets/Data/Xls/`
- 或随 AssetBundle 打包

## config.json 里的导出结构

`config/config.json` 把 Excel 表映射到 protobuf message，例如：

- `Role.xlsx -> RoleRawConfigList`
- `Bomb.xlsx -> BombRawConfigList`
- `Map/MapInfo.xlsx -> MapInfoRawConfigList`
- `Battle/Shape.xlsx -> ShapeRawConfigList`
- `Rank/RankLevel.xlsx -> RankLevelConfigList`

新增或修改表时，保持 `Definition.proto`、`config.json`、Excel 字段一致。

## 生成后的客户端配置类

客户端配置类位于：

```
Demo/Assets/Scripts/Configs/
```

例如 `Definition.cs`、`ActivityConfigs.cs`、`MapConfigs.cs`、`SkillConfigs.cs` 等。

## 服务器端配置读取

服务器统一在 `SweetServer_IOCP/PECommon/ConfigSvc/` 读取：

- `ConfigSvc.cs`
- `XlsConfigLoader.cs`
- 各类 `*ConfigManager.cs`

本地运行读取 `SweetServer_IOCP/PECommon/Configs/`，出包时复制到输出目录 `Configs/`。
