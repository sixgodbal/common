# 暴力抽射机制规格（足球 Boss）

> 初版：2026-10-19  
> 更新：2026-10-26，按当前代码实现重写（角色位移已改为减速，状态改为 Buff）  
> 适用：足球模式（`MapType.Bomb`）的 AI Boss（200002 / 200003 / 200004）。代码层面任何带 `BuffBrutalShot` 的角色都能触发，不限于 Boss。  
> 路径约定：客户端根 = `D:\sixgod\gitproject\test\Code\Demo\Assets\Scripts`

## 一、状态定义

- 使用 Buff：`BuffType.BrutalShot = 9`。
- 组件：`ECS/Components/BuffComponent.cs` 中的 `BuffBrutalShot`，只存 `endTime`。
  - `endTime > 0`：限时；
  - `endTime <= 0`：永久。
- 到期由 `ECS/NetSyncSystems/BuffBrutalShotSystem.cs` 清理，同时移除对应的 `BuffEffectItem` 头顶图标。
- 当前占位驱动：
  - 只在 `MapType.Bomb`；
  - 每隔 `AICommonLogic.BrutalShotInterval = 10s`；
  - 给所有存活的 `UnitType.AIBoss` 挂 `AICommonLogic.BrutalShotDuration = 4s`。
- `BrutalShotAction` 行为树节点已实现（冷却好了给自己挂 Buff），但 `boss_football_3` 当前没有接入，仍由占位系统驱动。

## 二、触发条件

`RoleKickBombSystem.CheckKick`：

1. 被踢的是普通泡泡（不带 `FootballComponent`）；足球不进入抽射分支。
2. 踢球者带 `BuffBrutalShot`。
3. 踢出方向的紧邻格没有被挡住：
   - 出界；
   - 墙 / 砖 / 河 / 钉子墙 / 图腾 / 活动砖；
   - 门；
   - 建筑。
4. 紧邻格有阻挡时，不触发抽射，回退到普通踢球（8 格 + 穿屏 + 落点回退）。

注意：泡泡、角色、地上的道具都**不算**阻挡，抽射本身会吸走同线泡泡。

## 三、结算规则

设被踢泡泡所在格为 P，踢出方向为 D，该方向的地图边界为 B。

### 1. 收集

**泡泡**：P→B 直线上（含 P、含边界），满足：

- `BombState.Normal`；
- `TryBomb == Success`；
- `EntityEndTime > 当前时间`；
- 未销毁。

飞行中的泡泡不参与。

**角色**：同一行 / 列、位于 P 与 B 之间的角色（含 P）：

- 英雄玩家；
- AI 角色；
- 分身 Clone；
- 排除踢球者自己；
- 排除 `RoleState.Death`。

### 2. 排序

泡泡和角色混在一起，按“距边界距离”从小到大排序。  
同距离实体的先后顺序未做额外约定，使用 `List.Sort` 的默认结果。

### 3. 角色结算

角色**不再瞬移**，改为减速：

- 降低 `FootballConstant.BrutalShotSlowValue = 3` 个速度档位；
- 最低保留 1 档（1 格/秒）；
- 持续 `FootballConstant.BrutalShotSlowDuration = 3s`；
- 通过通用 `BuffType.SpeedUp` 的负速度增量实现。

### 4. 泡泡结算

- 从边界向内找第一个可站立格；
- 然后把被扫到的泡泡按排序依次向内放；
- 遇墙 / 砖 / 河 / 门 / 建筑继续向内跳过；
- 直线之外的泡泡原地不动。

### 5. 空结果

如果直线上没有任何泡泡或角色，直接返回，不播放冲击线。

## 四、方向 → 边界

| 方向 | 边界 | 向内方向 |
|---|---|---|
| 左 | `x = 0` | `+x` |
| 右 | `x = col - 1` | `-x` |
| 下 | `y = 0` | `+y` |
| 上 | `y = row - 1` | `-y` |

## 五、算法伪代码

```text
# 入参：被踢泡泡所在格 P、方向 D
line = 从 P 沿 D 到边界的格子序列（含 P 与边界）

bubbles = [b in line
           if b.BombState == Normal
           and b.TryBomb == Success
           and b.EntityEndTime > now
           and !b.Destroyed]

roles = [r for r in 英雄/AI/分身
         if r != kicker
         and r.RoleState != Death
         and r.GridID 在 P 到边界之间（含 P）]

if bubbles.Count + roles.Count == 0: return

swept = bubbles + roles
sort swept by 距边界距离升序

# 角色：不移动，只挂减速
for r in roles:
    speedDelta = -min(3, max(0, r.SpeedIndex - 1))
    AddBuff(SpeedUp, 3000ms, speedDelta)

# 泡泡：从边界向内依次落位
cell = 从边界向内第一个可站立格
for b in bubbles:
    while cell 有障碍: cell 向内移一格
    MoveBombToGrid(b, cell)
    cell += 向内方向
```

## 六、泡泡移动细节

`AICommonLogic.MoveBombToGrid`：

- 更新 `GridID` / `Position` / `LastGridID` / `FlyTarget`；
- 从原格 `GetBombs().arr` 移除，加入新格 `arr`；
- `GetBombs().list` 不变；
- 状态重置为 `BombState.Normal`；
- 飞行方向清零，`FlyStep = 0`；
- `TryBomb` 重置为 `Success`，让 `BombChainSystem` 按新格重算连锁关系和爆炸范围。

## 九、和初版的差异

1. **状态载体**：`BrutalShotComponent` → `BuffBrutalShot` Buff。
2. **驱动系统**：`BrutalShotSystem` → `BuffBrutalShotSystem`。
3. **玩家处理**：从“瞬移到边界依次排列”改为“原地挂 3 秒减速”。
4. **表现**：钉墙特效不再使用；新增头顶 Buff 图标。
5. **触发限制**：代码不限制必须是 Boss，任何带 Buff 的角色都能触发；占位驱动只给 AI Boss 挂。
6. **空结果**：直线上没有实体时直接返回，不播冲击线。
7. **同距离排序**：没有额外规则，使用 `List.Sort` 的默认结果。
