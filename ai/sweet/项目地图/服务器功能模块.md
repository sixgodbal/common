## 新一代服务器 `SweetServer_IOCP`

### 服务进程

| 目录 | 职责 |
|---|---|
| `LoginServer/` | 登录、账号、房间、匹配、FakePlayer、Session |
| `DataServer/` | 玩家数据、Redis 存储、邮件、社交、排行、任务、转盘 |
| `BattleServer/` | 战斗房间与战斗账号 |
| `ManageServer/` | 管理通道/进程连接 |
| `SweetServer_IOCP/` | 最小控制台入口，用于启动/调试 |

### 公共库 `PECommon`

| 子目录 | 功能 |
|---|---|
| `Network/` | IOCP 服务端/客户端基类、KCP 配置、S2S RPC |
| `ConfigSvc/` | 配置加载与各类配置管理器 |
| `PB/` | protobuf 生成代码 |
| `Timer/` | 服务端计时器 |
| `Tools/` | 配置输出工具 |
| `Configs/` | 本地 JSON/xls 数据目录 |
| `MapData/` | 地图相关数据 |

## 构建与运行

```
build_all.bat    # 编译所有服务器
runall.ps1       # 启动 Login/Data/Battle/Manage + 启动 console
killall.bat      # 停止所有服务器
copy-configs.bat # 同步配置
```

正式/测试出包脚本位于 `BuildTools/`。
