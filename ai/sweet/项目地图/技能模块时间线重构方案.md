# 技能模块时间线重构方案

> 记录时间：2026-10-28  
> 状态：P0/P1 主体代码已落地，客户端 `Assembly-CSharp`、服务器 `PECommon` 编译通过；待 Unity 实机联调  
> 目标：把现有「每类技能一个 System + 四段状态机 + 技能内 CD」重构为「按需释放 + 时间线」  
> 路径约定：客户端根 = `D:\sixgod\gitproject\test\Code\Demo\Assets\Scripts`

---

## 0. 最终结论

1. **技能按需释放**：提供 `SkillService`，任何 Entity 都可以调用 `UseSkill` 使用技能；每次释放创建一个临时施法实体，时间线播完自动销毁。
2. **技能内部不再有 CD/状态机**：删除 `SkillCDComponent`、`SkillState`、前摇/持续/后摇组件；时间线只负责一次释放。
3. **自动释放单独配置**：`Skill.xlsx` 增加 `autoUse` 字段。  
   - `autoUse = 1`：由 `SkillAutoCastSystem` 按 `cd` 循环自动调用 `UseSkill`（图腾、蛇身、Boss 的旧自动技能靠这个保留）。  
   - `autoUse = 0`：代码不自动释放，完全由行为树/其他系统调用 `UseSkill`。
4. **配置精简**：删除 `areaFilter / areaFilterCount / areaShape / teamType`，新增通用 `param` 键值字段；每种技能类型自己解析需要的参数。
5. **阵型旋转默认关闭**：`isRotate` 字段默认 `false`，预览、阵型生成、范围判定统一使用。
6. **打断**：施法者死亡、被困、石化时立即终止施法。
7. **单格阵型**：`areaShape <= 0` 按单格处理。

## 1. 现有系统盘点

### 1.1 现有能力

| 能力 | 现有实现 |
|---|---|
| 技能实体 | `EntityFactoryService.CreateSkillEntity`，每个技能常驻一个 Entity |
| 冷却/状态机 | `SkillCDComponent` + `SkillState`（Ready/CD/前摇/Doing/后摇） |
| 阵型 | `Skill_ShapeSystem` → `SkillLogic.AddShape` → `ShapeSystem` |
| 范围 Buff | `Skill_EffectSystem` → `AICommonLogic.TriggerBuff` |
| 撒道具 | `Skill_DropItemSystem` → `CommonLogic.ThrowingItem` |
| 碰撞 Buff | `Skill_TouchEffectSystem` + `TouchEffectSystem` |
| 按掉血释放 | 行为树 `SkillAction` 递归解析 `SkillType.DoSkill_ByBlood` |
| 预览 | `AddTarget` / `ShowSeek` + `TrackMarkSystem` |
| UI | `SkillViewItem` 读 `SkillInfo.skills[0]` 和 `SkillCDComponent` |
| 被动计数 | `SkillSystem`（走 5 格/放 5 个泡泡触发飞镖），与技能配置无关 |

### 1.2 现有问题

1. 技能释放时机被 CD 状态机绑死，行为树无法直接控制单个技能的节奏。
2. 技能实体常驻，`SkillInfo` 维护 `List<Game.Entity>`，快照和清理都复杂。
3. `areaFilter / areaShape / teamType` 只有阵型/范围技能使用，撒道具、碰撞、按掉血技能完全用不到。
4. `Skill_ShapeSystem` 读 owner 方向，实际阵型不旋转；预览却旋转，表现不一致。
5. `areaShape = 0` 会空引用。
6. `SkillLogic.EnterSkill`、`RoleEffectSystem`、旧时间线注释代码都是死代码。

## 2. 新架构

```text
行为树 / 其他系统
        │
        ▼
SkillService.Cast(caster, skillId)
        │
        ├─ 校验施法者、配置、类型
        ├─ ByBlood：解析成子技能 ID 后递归释放
        ├─ 创建临时施法实体（SkillCastEntity）
        │      ├─ OwnerUID
        │      ├─ SkillConfig
        │      ├─ SkillTimeLine
        │      ├─ SkillTarget / SkillDirection（按需）
        │      └─ Skill_TouchEffect（碰撞类）
        └─ 时间线由 SkillTimeLineSystem 统一 tick，播完销毁实体

SkillAutoCastSystem
        └─ 只处理 autoUse = 1 的技能，按 cd 循环调用 UseSkill
```

### 2.1 技能释放载体

- 每次 `UseSkill` 创建一个临时技能实体。
- 实体只活一次施法，时间线结束、被打断、施法者销毁时销毁。
- 不再为每个技能创建常驻 Entity，不再需要 `SkillInfo.skills` 存 Entity。
- 同一个施法者允许不同技能并行；同一个 `skillId` 同时只允许一个施法实例（避免行为树/自动系统重复触发）。

### 2.2 自动释放

- `autoUse = 1` + `cd > 0`：`SkillAutoCastSystem` 维护每个技能的计时器，到点调用 `UseSkill`。
- `autoUse = 0`：代码不自动释放；行为树通过 `SkillAction` 调用 `UseSkill`，节奏由行为树控制。
- `cd` 字段保留，但只用于 `autoUse = 1`；手动释放不检查 CD。

### 3.4 `SkillService.Cast` 流程

```csharp
public bool Cast(Game.Entity caster, int skillId, SkillCastSource source)
{
    if (caster == null || caster.HasDestroyed()) return false;
    if (SkillLogic.IsInterrupted(_context, caster)) return false;

    SkillConfig config = _context.GetConfigService().instance.GetSkillConfig(skillId);
    if (config == null) return false;

    // 自动释放只跑 autoUse 技能；手动释放不限制
    if (source == SkillCastSource.Auto && !config.autoUse) return false;

    // 同一个技能同时只允许一个施法实例
    if (IsCasting(caster, skillId)) return false;

    SkillType type = (SkillType)config.Type;
    if (type == SkillType.DoSkill_ByBlood)
        return CastByBlood(caster, config);   // 解析后递归 Cast

    if (!SkillTimeLineFactory.IsSupported(type)) return false;

    Game.Entity cast = _context.CreateEntity();
    cast.AddUID(UidUtils.Uid);
    cast.AddOwnerUID(caster.GetUID().value);
    cast.AddSkillConfig(config);
    cast.AddSkillTarget(SeekType.None, new ulong[0], new FixVector2[0]);
    cast.AddSkillDirection(MoveDirectionType.None);

    if (caster.HasTeam()) cast.AddTeam(caster.GetTeam().value);
    else cast.AddTeam(TeamEnum.None);

    if (caster.HasGridID()) cast.AddGridID(caster.GetGridID().value);
    if (caster.HasPosition()) cast.AddPosition(caster.GetPosition().value);

    SkillTimeLine line = SkillTimeLineFactory.Build(_context, cast);
    cast.AddSkillTimeLine(
        SkillCastState.Running,
        Fix.zero,
        line.TotalTime,
        0,
        line);

    // 类型特有初始化：碰撞类加 Skill_TouchEffect
    SkillTimeLineFactory.InitCast(_context, cast, config);

    cast.AddUnitType(UnitType.Skill);

    OnCastStarted(caster, config);
    return true;
}
```

`OnCastStarted`：

- 给 owner 的 `AIBehavior.behaviorTree.SendEvent(AIConstant.DoSkillTrigger)`，保持旧行为树能收到“开始放技能”事件。

### 4.4 `SkillTimeLine`

```csharp
public sealed class SkillTimeLine
{
    private readonly List<SkillTimeEvent> events = new List<SkillTimeEvent>(8);

    public int Count => events.Count;
    public SkillTimeEvent this[int index] => events[index];
    public Fix TotalTime { get; private set; }

    public void Clear()
    {
        events.Clear();
        TotalTime = Fix.zero;
    }

    public void Add(Fix time, Action action, string name = null)
    {
        events.Add(new SkillTimeEvent
        {
            time = time,
            action = action,
            order = events.Count,
            name = name,
        });
    }

    public void SetTotalTime(Fix time) { TotalTime = time; }

    public void Sort()
    {
        events.Sort((a, b) =>
        {
            if (a.time < b.time) return -1;
            if (a.time > b.time) return 1;
            return a.order.CompareTo(b.order);
        });
    }
}

public struct SkillTimeEvent
{
    public Fix time;
    public Action action;
    public int order;
    public string name;
}
```

## 5. 时间线 Builder

### 5.1 基类

```csharp
public abstract class SkillItem_Base
{
    protected readonly GameContext _context;
    protected readonly Game.Entity _skill;
    protected readonly SkillConfig _config;
    protected readonly SkillTimeLine _timeLine = new SkillTimeLine();

    protected readonly Fix ForwardTime;   // dotime[0]
    protected readonly Fix DoingTime;     // dotime[1]
    protected readonly Fix BackTime;      // dotime[2]

    protected bool isRotate = false;      // 阵型/范围是否按方向旋转，默认关闭

    protected SkillItem_Base(GameContext context, Game.Entity skill) { ... }

    public SkillTimeLine Build()
    {
        _timeLine.Clear();

        _timeLine.Add(0, PlayAudioPre);
        _timeLine.Add(ForwardTime, PlayAudioDo);
        _timeLine.Add(ForwardTime + DoingTime, OnReleaseEnd);

        InitTimeLine();
        _timeLine.SetTotalTime(ForwardTime + DoingTime + BackTime);
        _timeLine.Sort();
        return _timeLine;
    }

    protected abstract void InitTimeLine();
}
```

|---|---|---|
| `PlayAudioPre` | 播 `audio_pre` | `_Enter_ForwardSway` |
| `PlayAudioDo` | 播 `audio_do` | `_Enter_Doing` |

## 6. 统一驱动 System

### 6.1 `SkillTimeLineSystem`

```csharp
public sealed class SkillTimeLineSystem : IExecuteSystem
{
    private readonly GameContext _context;
    private readonly Fix _deltaTime = (Fix)ClientConfig.ClientLogicFrameDeltaSec;

    public void Execute()
    {
        if (_context.GetGameProgress().value != GameProgressState.InGame) return;

        var entities = _context.GetGroup(GameSkillTimeLineMatcher.SkillTimeLine).GetEntities();
        for (int i = 0; i < entities.Length; i++)
        {
            Game.Entity cast = entities[i];
            if (cast.HasDestroyed()) continue;

            if (SkillLogic.IsInterrupted(_context, cast))
            {
                DestroyCast(cast);
                continue;
            }

            var com = cast.GetSkillTimeLine();
            if (com.state == SkillCastState.WaitingTouch)
            {
                SkillActions.FollowOwnerGrid(_context, cast);
                continue;
            }

            com.timer += _deltaTime;
            DispatchDueEvents(cast, com);

            if (com.state != SkillCastState.Running) continue;
            if (com.nextIndex >= com.line.Count && com.timer >= com.totalTime)
                DestroyCast(cast);
        }
    }
}
```

`DispatchDueEvents`：

```csharp
while (com.nextIndex < com.line.Count && com.line[com.nextIndex].time <= com.timer)
{
    SkillTimeEvent evt = com.line[com.nextIndex];
    com.nextIndex++;
    evt.action?.Invoke();

    if (com.state != SkillCastState.Running) return;
}
```

`DestroyCast`：

### 6.2 打断

统一判断：

```csharp
public static bool IsInterrupted(GameContext context, Game.Entity casterOrCast)
{
    Game.Entity owner = casterOrCast;
    if (casterOrCast.HasOwnerUID())
        owner = context.GetEntityFactoryService().instance.GetEntity(casterOrCast.GetOwnerUID().value);

    if (owner == null || owner.HasDestroyed()) return true;

    if (owner.HasRoleState())
    {
        switch (owner.GetRoleState().value)
        {
            case RoleState.Death:
            case RoleState.TryTrapped:
            case RoleState.Trapped:
            case RoleState.Yhc:
                return true;
        }
    }

    if (owner.HasBuffPetrify()) return true;

    return false;
}
```

- 每次 tick 施法实体时检查。
- 施法者死亡/被困/石化 → 直接销毁施法实体。
- 已经结算的阵型/Buff/道具不回滚。
- `SkillService.Interrupt(caster)` 供 `EntityDestroySystem` / `AIBloodSystem` 主动调用，遍历该施法者的施法实体并销毁。
- 自动释放的 CD 在施法开始时已经重置，所以打断后下一次仍按完整 CD。

### 6.3 `SkillAutoCastSystem`

```csharp
public sealed class SkillAutoCastSystem : IExecuteSystem
{
    private readonly GameContext _context;
    private readonly Fix _deltaTime = (Fix)ClientConfig.ClientLogicFrameDeltaSec;

    public void Execute()
    {
        if (_context.GetGameProgress().value != GameProgressState.InGame) return;

        var owners = _context.GetGroup(GameSkillAutoCastMatcher.SkillAutoCast).GetEntities();
        for (int i = 0; i < owners.Length; i++)
        {
            Game.Entity owner = owners[i];
            if (owner.HasDestroyed()) continue;
            if (SkillLogic.IsInterrupted(_context, owner)) continue;

            var com = owner.GetSkillAutoCast();
            for (int j = 0; j < com.skills.Count; j++)
            {
                SkillAutoEntry entry = com.skills[j];
                if (entry.cdTime <= 0) continue;

                // 技能释放中不推进 CD，释放结束后才开始计算完整 CD。
                if (_context.GetSkillService().instance.IsCasting(owner, entry.skillId))
                    continue;

                entry.runTime += _deltaTime;
                if (entry.runTime < entry.cdTime) continue;

                if (_context.GetSkillService().instance.Cast(owner, entry.skillId, SkillCastSource.Auto))
                    entry.runTime = Fix.zero;
            }
        }
    }
}
```

- 技能释放期间不推进 CD，释放结束后才开始计算完整 CD。
- 到点但释放失败（施法者被打断、同技能正在释放）时保持计时器满值，下一帧重试。
- `autoUse = 0` 的技能不进入此系统。

## 7. 配置改造

### 7.1 Skill.xlsx 字段调整

删除：

- `areaFilter`
- `areaFilterCount`
- `areaShape`
- `teamType`

新增：

- `param`：通用键值参数，各技能类型自己解析。
- `autoUse`：是否自动释放。

保留：

- `ID / name / icon / type / args / cd / dotime / aniForward / audio_pre / audio_do`
- `cd` 只用于 `autoUse = 1`；手动技能忽略。

`Definition.proto`：

```proto
message SkillConfig{
    required int32 ID = 1;
    required string name = 2;
    required string icon = 3;
    reserved 4, 5, 6, 7;
    required int32 type = 8;
    required string args = 9;
    required int32 cd = 10;
    required string dotime = 11;
    required string aniForward = 12;
    required string audio_pre = 13;
    required string audio_do = 14;
    optional string param = 15;
    optional bool autoUse = 16;
}
```

### 7.2 `param` 格式

键值对，`;` 分隔，`=` 连接：

```text
filter=Player;shape=101001;team=Enemy;count=1
```

支持的键：

| 键 | 值 | 说明 |
|---|---|---|
| `filter` | `Self` / `Player` / `Grid_Random` | `SkillAreaFilterType` |
| `count` | 整数 | 默认 1；当前只保留兼容 |
| `shape` | 整数 | 阵型 ID；`<= 0` 按单格 |
| `team` | `Enemy` / `Friend` / `All` | `TargetCampType` |

各类型读取：

| 技能类型 | 读取 |
|---|---|
| Shape | `filter / shape`（`team` 不用） |
| Effect | `filter / shape / team` |
| DropItem | 不读 `param` |
| Touch | 不读 `param`（沿用 owner 队伍判断） |
| ByBlood | 不读 `param` |

工具类：


## 8. 行为树改造

`SkillAction` 改为只调用接口，不再自己解析类型：

```csharp
public class SkillAction : Action
{
    public int skillId;

    public override TaskStatus OnUpdate()
    {
        Game.Entity aiPlayer = AICommonLogic.GetAI(_context, roleIndex);
        if (aiPlayer == null) return TaskStatus.Failure;

        _context.GetSkillService().instance.Cast(aiPlayer, skillId);
        return TaskStatus.Success;
    }
}
```

- `ByBlood` 由 `SkillService.Cast` 内部解析成子技能 ID，行为树不需要知道。
- 行为树用 `Cooldown` / `Wait` / `Sequence` 节点控制释放间隔，技能代码不再检查 CD。
- 旧行为树里 `SkillAction` 配置的 `skillId` 保持不变。
- 图腾/蛇身没有行为树，继续用 `autoUse = 1`。

## 9. 各类型迁移

### 9.1 阵型（type = 3）

```csharp
_timeLine.Add(0, LockTarget);
_timeLine.Add(ForwardTime, SpawnShape);
```

- `SkillParam` 解析 `filter / shape`。
- `isRotate = false` 时预览、`AddShape`、范围判定都不旋转。
- `shape.delay` 继续由 `BombShape` 队列 + `ShapeSystem` 处理。

### 9.2 范围 Buff（type = 4）

```csharp
_timeLine.Add(0, LockTarget);
_timeLine.Add(ForwardTime, TriggerAreaEffect);
```

- `SkillParam` 解析 `filter / shape / team`。
- `args` 继续是 `BuffType, duration, ...`。
- `areaShape <= 0` 时按单格，范围判定只命中中心格。

### 9.3 撒道具（type = 1）

```csharp
_timeLine.Add(ForwardTime, DropItems);
```

- `args` 是 `itemId,count,itemId,count...`。
- 实体技能用 owner 的 `GridID` 作为中心；行为树即时调用也走同一套，用 owner 的 `Position`。
- `autoUse = 1` 的图腾/蛇身仍由自动系统触发。

### 9.4 碰撞 Buff（type = 5）

```csharp
_timeLine.Add(ForwardTime, EnableTouch);
_timeLine.Add(ForwardTime, WaitTouch);
```

- `args` 是 `BuffType,duration,...`。
- `EnableTouch` 先同步 owner 格子，再置 `canTrigger = true`。
- `TouchEffectSystem` 结算后置 `canTrigger = false`，并让施法实体从 `WaitingTouch` 恢复。
- 一次触发对范围内所有敌人结算，保持旧行为。

### 9.5 按掉血释放（type = 2）

- 不创建时间线。
- `SkillService.Cast` 检测到 type 2 后：

```csharp
int missingBlood = owner.GetBossConfig().value.Blood - owner.GetRoleBlood().value;
int index = Math.Min(missingBlood, args.Length) - 1;
return Cast(owner, args[index], source);
```

- `args` 是子技能 ID 列表。
- 目前子技能只会是 DropItem，其他类型走各自的安全判断。

### 9.6 type 6（5555 爆炸波）

- 本次不实现。
- `SkillTimeLineFactory.IsSupported` 返回 false，`Cast` 打 error 并返回 false。
- 后续新增 `FlameSkillTimeLineBuilder` 即可。

## 14. 风险与取舍

| 风险 | 说明 | 处理 |
|---|---|---|
| 行为树技能迁移 | 现有怪物技能靠 CD 自动放；改 `autoUse=0` 后必须补行为树节点，否则不放技能 | 先保持 `autoUse=1`，逐个改 BT；改一个验证一个 |
| 配置迁移 | 删除 4 列、新增 `param/autoUse`，所有行都要改 | 用脚本批量生成 `param`，再人工抽查 |
| 旧录像 | 组件/枚举/`SkillInfo` 结构变化，旧录像不兼容 | 已确认直接替换 |
| 时间点误差 | 新时间线在释放同帧派发 t=0 | 允许 ±1 帧 |
| 委托序列化 | `Action` 闭包不能可靠进快照 | 只序列化进度，恢复时重建 |
| 同帧顺序 | `List.Sort` 不稳定 | 事件带 `order` 二级排序 |
| 碰撞多目标 | 旧逻辑一次触发对范围内所有敌人结算 | 保持 |
| 自动释放与手动释放重叠 | BT 和 Auto 同时触发同一技能 | `Cast` 检查同 skillId 正在施法，重复返回 false |

## 15. 已确认决策

1. **释放载体**：临时施法实体，播完销毁；不再常驻技能实体。
2. **自动释放**：`Skill.xlsx` 增加 `autoUse`；`autoUse=1` 由 `SkillAutoCastSystem` 按 `cd` 循环调用，`autoUse=0` 由行为树/其他系统调用。
3. **通用参数**：新增 `param` 键值字段，删除 `areaFilter / areaFilterCount / areaShape / teamType`；各技能类型自己解析。
4. **旋转**：`isRotate` 默认 `false`，统一控制预览、阵型生成、范围判定。
5. **打断**：死亡、被困、石化立即终止；进入下一次自动 CD（自动技能）。
6. **单格**：`areaShape <= 0` 按单格处理。
7. **UI**：`SkillInfo` 保留技能 ID 和图标；自动技能显示 CD，手动技能不显示 CD。
