# 探险模式区域功能（Region）设计与实现总结

> 记录时间：2026-10-27  
> 状态：核心代码已实现，待配置区域数据、导表、打 AB 后实机联调  
> 用途：记录探险模式矩形区域锁的完整方案、实际代码落点、配置步骤、注意事项和测试清单  

## 0. 一句话

**用地图编辑器配置矩形区域，每个 spawner 指定自己使用哪个区域；波次生成怪物后给怪挂 `RegionComponent`；玩家只被本地客户端限制不能离开当前激活区域，AI 的移动、寻路、索敌、攻击/危险扫描全部限制在自己的区域内，实际伤害不限制；区域模式下不再使用门。**

---

## 1. 背景与目标

QQ堂探险模式中，每张地图由若干“有怪的区域”组成：

- 玩家进入区域后，如果该区域的怪没清完，就不能离开；
- 往外走会被挡住，同时整个区域范围闪一层很透明的黑色遮罩；
- 怪被限制在自己的区域内移动、索敌、寻路，不能跨区域。

当前代码的现状：

- 刷怪是波次制，`SpawnerSystem` 一次只跑一个 spawner；
- 2002 地图（森林3，Level 2001）有 4 个 spawner；
- 原“门”逻辑是把 `Level.DoorPos` 映射到地图的 `team3SpawnPos`，在运行时创建 `2055` 墙体，清完当前 spawner 后拆掉；
- 2002 的 `doorArr` 是空的，没有真正的 `Door` 元素；
- 地图本身不是封闭房间，存在绕过门墙的路径，所以不能靠门墙做区域锁。

本功能用**矩形区域逻辑**替代门，边界由矩形判断，不再依赖地图墙体是否封闭。

## 2. 最终规则

| 项 | 结论 |
|---|---|
| 区域形状 | 矩形 |
| 区域配置位置 | 地图编辑器（MapEditor） |
| 区域字段 | `id, x, y, w, h`，ID 可在编辑器编辑 |
| 区域重叠 | 允许 |
| 区域留空 | 允许，不警告 |
| 区域 ID | 必须唯一；重复打印 error 并禁止导出 |
| spawner 与区域关系 | 反向配置：`Spawner.xlsx` 每个 spawner 配置 `regionId` |
| 刷怪点不在区域内 | 打印 error，不给该怪加 `RegionComponent` |
| `regionId = 0` / 找不到区域 | 打印 error，不加组件，不限制 |
| 区域判定组件 | `RegionComponent { int regionId }`，由 `SpawnerSystem` 创建怪后添加 |
| Boss 召唤物 | 预留继承接口，召唤物创建后继承 boss 的 `RegionComponent` |
| 玩家锁区 | 只限制本地主控玩家；区域外可进入，进入后被锁 |
| op 校验 | 不做；其他客户端走出去就让他走出去 |
| 激活区域 | 当前 spawner 的 `regionId` 对应区域 |
| 解锁时机 | 保持到下一波 spawner 真正生成、区域切换时再解除 |
| 区域遮罩 | 覆盖整个激活区域矩形，闪烁 |
| AI 限制 | 移动、寻路、索敌、攻击/危险扫描、行为树条件节点 |
| AI 实际伤害 | 不限制；爆炸、火焰、弹道、技能效果照常 |
| 门 | 区域模式下不再创建/拆除门墙；`doorArr` 逻辑不改 |
| AgentKernel | 不使用，不修改 |
| 其他位移入口 | 先记录 TODO，暂不实现 |
| 玩家技能 | 目前没有；以后允许选区域外目标，不限制 |
| 服务器 | 不参与战斗模拟，不改 |

## 3. 数据结构

### 3.1 区域信息 `RegionInfo`

地图编辑器、客户端 `MapFile` / `MapConfig` 共用：

```csharp
[Serializable]
public class RegionInfo
{
    public int id;
    public int x; // 左下角格子 x
    public int y; // 左下角格子 y
    public int w; // 宽，单位格子
    public int h; // 高，单位格子
}
```

- 坐标是格子坐标，不是世界坐标；
- 判断用半开区间：`grid.x >= x && grid.x < x + w && grid.y >= y && grid.y < y + h`；
- 区域之间允许重叠；
- 区域允许留空；
- ID 必须唯一。

### 3.2 区域组件 `RegionComponent`

文件：`Demo/Assets/Scripts/ECS/Components/RegionComponent.cs`

```csharp
[Context(typeof(GameContext))]
public sealed class RegionComponent : IComponent
{
    public int regionId;
}
```

- 只存 `regionId`，矩形从地图配置按 ID 查；
- 只要 entity 有该组件，就受区域限制；
- 玩家不加该组件；
- Entitas 自动生成 `HasRegion/AddRegion/GetRegion` 等代码；
- 录像快照 Codec 会随 Entitas 组件生成，需实测恢复。

### 3.3 Spawner 配置

`Xls/xls/Battle/Spawner.xlsx` 已增加第 8 列：

```text
H1 = 区域ID
H2 = regionId
H3 以下 = 0
```

`Xls/Definition.proto`：

```proto
message SpawnerConfig{
    ...
    optional int32 regionId = 7;
}
```

客户端/服务器 `SpawnerConfig.regionId` 已生成。

> 当前所有 spawner 的 `regionId` 都是 0，功能默认关闭；需要配置。

## 4. 数据流

```text
MapEditor 配置区域矩形
    ↓ 保存/导出
地图 bytes（MapFile.regionInfoArr）
    ↓ 客户端加载
MapConfig.Regions / RegionDic

Spawner.xlsx 配置 regionId
    ↓ 导表
SpawnerConfig.regionId
    ↓ SpawnerSystem 创建怪
RegionComponent { regionId }
    ↓
RegionLogic 用 id 查矩形，限制 AI / 激活玩家区域
```

## 5. MapEditor 实现

### 5.1 数据

`MapEditor/Assets/Scripts/MapFile.cs`

```csharp
[Serializable]
public class RegionInfo
{
    public int id;
    public int x, y, w, h;
}

[OptionalField]
public RegionInfo[] regionInfoArr;
```

- `[OptionalField]` 兼容旧地图；
- 旧地图 `regionInfoArr == null` 时，客户端区域功能关闭；
- MapEditor 和客户端 `MapFile` / `RegionInfo` 字段名、类型必须一致；
- 两边都是 Unity `Assembly-CSharp`，BinaryFormatter 才能正常反序列化。

### 5.2 编辑器 UI

新增 `MapEditor/Assets/Scripts/RegionEditorPanel.cs`，并在 `ViewManager.Awake` 中动态添加。

当前实现是方案 A：

- 左上角“区域配置”按钮；
- 面板列表每行显示 `ID / X / Y / W / H`；
- 添加、删除、修改；
- 区域 ID 可直接编辑；
- 重复 ID 标红并禁止导出；
- 区域越界（超出地图、宽高 <= 0）在行内显示“越界”红字，但不禁止导出；
- 地图上绘制半透明填充 + 描边预览，跟随地图缩放/平移；
- 区域列表随地图保存/加载/导出/导入；
- 不做拖拽、不做区域撤销。

### 5.3 保存/导出

`MapSnapshot` 增加 `List<RegionInfo> regions`：

- `CaptureCurrentSnapshot` 收集当前区域；
- `CreateSnapshotFromMapFile` 读取地图区域；
- `ApplySnapshotToScene` 恢复区域；
- `ToMapFile` 输出 `regionInfoArr`；
- `ResizeSnapshot` 保留区域坐标（可能越界，编辑器会标红）；
- `HasSameContent` 比较区域列表。

`ExportCurrentMap` 导出前调用 `ValidateRegionsForExport`：

- 区域 ID 重复 → `Debug.LogError` + `ShowTips`，**不写文件**；
- 保存地图仍允许，只有导出被拦截。

### 5.4 编辑器输入屏蔽

`RegionEditorPanel.BlocksInput` 会在鼠标位于面板/按钮上时为 true：

- `ViewManager.IsPointerOverUI()` 会返回 true；
- 触摸输入守卫也加了该判断；
- 防止在面板上操作时误画地图。

## 7. 区域运行时 `RegionLogic`

文件：`Demo/Assets/Scripts/ECS/Logic/RegionLogic.cs`

主要接口：

```csharp
GetRegion(context, entity)
GetRegion(context, regionId)
InRegion(region, grid)
GetActiveRegion(context)
CanLocalPlayerLeave(context, player, targetGrid)
CanAIEnter(context, ai, targetGrid)
CanSee(context, ai, target)
InheritRegion(owner, child)
IsBlockedByRegion(context, entity, targetGrid)
```

### 7.1 激活区域

- 当前 spawner 的 `regionId` 对应区域 = 激活区域；
- `RegionLogic.GetActiveRegion` 使用 `LevelInfo.spawnerIndex` 对应的 `SpawnerInfo.regionId`；
- 当前 spawner 完成后，不立刻清空；
- 保持到下一波 spawner 真正生成、`spawnerIndex` 切换时再重新计算；
- 如果下一波使用同一个区域，锁定继续；
- 如果下一波换区域，切换到新区域；
- 如果没有下一波（关卡结束），清空；
- 如果当前 spawner 的 `regionId` 为 0 或找不到，返回 null，不锁玩家。

### 7.2 重叠区域

- 允许；
- 每个怪用自己 `RegionComponent.regionId` 的区域；
- 玩家锁用“当前 spawner 的激活区域”；
- 区域遮罩只显示激活区域；
- 如果玩家同时处于多个重叠区域，只有激活区域参与玩家锁。

### 7.3 留空

- 区域之间可以留空；
- 玩家在空洞里不锁；
- 不打印警告。

## 8. Spawner 实现

`Demo/Assets/Scripts/ECS/NetSyncSystems/AI/SpawnerSystem.cs`

### 8.1 SpawnerInfo

```csharp
public class SpawnerInfo
{
    public bool isopen;
    public int spawnerId;
    public int regionId;
    public bool cleared;
    public List<int> monsterIds;
    public int monster_count;
    public int kill_count;
}
```

### 8.2 初始化

`InitSpawners`：

- 从 `SpawnerConfig.regionId` 写入 `SpawnerInfo.regionId`；
- 如果地图有区域（`mapConfig.Regions.Count > 0`），跳过 `door_pos` 的门墙创建；
- 否则保留原有门逻辑，其他地图不受影响。

### 8.3 创建怪时加组件

`CreateAIPlayer` 创建 entity 后调用 `AddRegionComponent`：

```text
spawner.regionId > 0
    → 查找 RegionInfo
        → 找不到：error，日志，不加组件
        → 刷怪点不在区域内：error，日志，不加组件
        → 正常：AddRegion(spawner.regionId)
```

- 有组件 → 该怪受区域限制；
- 没有组件 → 不限制（配置错误时会这样）。

### 8.4 完成与解锁

`OnRoleStateUpdate`：

- 按 `entity.GetSpawnerId()` 找到对应 spawner；
- `kill_count++`；
- 达标后：
  - `OnSpawnerFinish(i)`；
  - `spawner.cleared = true`；
  - 如果 `i == LevelInfo.spawnerIndex`，设置 `spawnerComplete = true`；
- `SpawnerSystem.Execute` 下一帧 `DoNext` 推进波次；
- `RegionLogic` 根据新的 `spawnerIndex` 切换激活区域。

区域模式下 `OnSpawnerFinish` 不再拆门，只做完成标记。

### 8.5 Boss 召唤物

`RegionLogic.InheritRegion(owner, child)` 已预留：

- 如果 owner 有 `RegionComponent`，child 没有，则复制 `regionId`；
- 当前代码没有独立的 Boss 召唤物创建入口；
- 以后新增召唤物时，在创建后调用一次。

## 9. 玩家移动与区域遮罩

### 9.1 只锁本地主控玩家

`Demo/Assets/Scripts/ECS/LocalSystems/PassableLogic.cs`

`GetPassableReason` 在炸弹/墙体判断前调用 `RegionLogic.IsBlockedByRegion`：

```text
entity.HasRegion()   → AI
    目标格不在自己区域 → 阻挡

entity.HasMainPlayer() → 本地主控玩家
    当前格在激活区域内、目标格在区域外 → 阻挡（RegionLocked）

其他（远程玩家等）→ 不拦
```

- 远程玩家没有 `RegionComponent`、没有 `MainPlayer`，不受影响；
- 不在 `EmitInputSystem` 做校验；
- 不因为区域锁导致不同步；
- 其他客户端异常走出去，其他客户端照常显示。

### 9.2 进入规则

- 玩家从区域外进入激活区域：允许；
- 进入后：不能离开；
- 区域解锁后：可以离开；
- 玩家在区域外：不锁。

### 9.3 被挡事件

`PlayerMoveSystem.TryGetTargetPos`：

- 如果 `newPos == curPos` 且输入方向非 Stop；
- 计算下一格，如果 `RegionLogic.CanLocalPlayerLeave` 返回 false；
- 发送 `EvtID.BATTLE_REGION_LOCKED`，参数为激活区域 ID。

### 9.4 区域遮罩

`Demo/Assets/Scripts/View/Map/RegionMaskManager.cs`

- `ViewManager.OnMapGridsAdd` 在 `mapConfig.Regions.Count > 0` 时创建 `RegionMaskRoot` 和 `RegionMaskManager`；
- 每个区域一个矩形 quad；
- 覆盖整个区域矩形，包括墙和空区域；
- 黑色，alpha 约 `0.12`；
- 闪烁：0 → 0.12 → 0，时长 0.3 秒；
- 冷却 0.45 秒；
- 持续推边界重复闪；
- 只对本地主控玩家当前所在激活区域生效；
- 纯本地表现，不走网络。

### 9.5 其他位移入口

## 10. AI 限制

### 10.1 原则

- AI 用自己 entity 上的 `RegionComponent`，不是全局激活区域；
- 只限制“扫描/选目标/寻路/移动”；
- 实际伤害、爆炸、弹道、技能触发不限制；
- 没有 `RegionComponent` 的 AI 不限制（配置错误时会这样）。

### 10.2 寻路

`Demo/Assets/Scripts/ECS/Logic/FindPathLogic.cs`

- 两个 `CheckGridAround` 重载都在越界判断后加：

```csharp
if (!RegionLogic.CanAIEnter(_context, _findInfo.entity, tempOffset)) continue;
```

- BFS 扩展、目标筛选都不会进入区域外；
- 没有 `RegionComponent` 的实体不受影响；
- `FindPathAction`、`FindPathDirectionAction`、`FindPathToTargetAction`、`FindPathToTargetGrid`、`GetTargetGridID`、`CheckDistanceAction` 通过底层自动生效。

### 10.3 分数/势能

`Demo/Assets/Scripts/ECS/Logic/MapScoreLogic.cs`

- `CalScore` 增加可选 `RegionInfo region` 参数；
- 扩散时区域外直接跳过。

调用方：

- `AIPathScore_ToPlayerSystem` 传激活区域，并只把区域内英雄计入；
- `AIPathScore_SnakeSystem` 传每只蛇自己的区域；
- 其他旧调用传默认 null，不受影响。

### 10.4 索敌

`Demo/Assets/Scripts/ECS/Logic/SeekLogic.cs`

- `SeekEntity_Player(context, RegionInfo region = null)`；
- 只返回区域内英雄；
- `DoSeekTarget` 传激活区域；
- `Skill_BaseSystem` 只有技能 owner 是 AI（`HasSpawnerId`）时传激活区域；玩家技能传 null，不限制。

### 10.5 攻击

`Demo/Assets/Scripts/ECS/Logic/AttackLogic.cs`

- `CanAtkPlayer(context, gridId, RegionInfo region = null)`；
- 遍历玩家时过滤区域外目标；
- `FindPathLogic` 的 `AtkPlayer` / `AtkPlayerLink` 传 AI 区域；
- `CanAtkPlayerConditional`、`GridConditional` 传 AI 区域。

### 10.6 危险/攻击扫描

- `AIDangerCheckSystem.CheckDangerOne`：
  - 如果 AI 有 `RegionComponent`，炸弹格不在 AI 区域内则忽略；
  - 不影响英雄分支。
- `IsDangerGridConditional`：
  - 目标偏移格不在 AI 区域 → Failure。
- `DoSkillBombShape`：
  - 目标英雄必须 `RegionLogic.CanSee`（在同一区域）。

### 10.7 行为树条件节点

已修改：

- `HasAliveEnemy.cs`
  - 增加 `RegionLogic.CanSee(_context, my, hero)`。
- `HasTrappedPlayer.cs`
  - 增加 `RegionLogic.CanSee(_context, aiPlayer, playerEntity)`。

  - 玩家不在 AI 区域时返回 Failure。

### 10.8 移动节点

这些节点直接改位置，不走 `PassableLogic`，已单独加检查：

## 14. 注意事项 / 已知问题

### 14.1 功能默认关闭

- `Spawner.xlsx` 的 `regionId` 当前全部为 0；
- MapEditor 的地图还没有区域数据；
- 在配置前，不会生成 `RegionComponent`，玩家也不会被锁；
- `MapConfig.Regions` 为空时，地图按旧逻辑运行。

### 14.2 区域 ID 与配置一致性

- 区域 ID 在 MapEditor 配，`Spawner.xlsx.regionId` 引用；
- 两边不一致时只能靠客户端 error 日志发现；
- 区域 ID 必须唯一：
  - MapEditor 重复 ID：error + 禁止导出；
  - 客户端重复 ID：error + 保留第一条；
- 区域可以重叠，但 ID 不能重复。

### 14.3 刷怪点不在区域

- `SpawnerSystem` 会打印 error；
- **该怪不加 `RegionComponent`**，所以它不受区域限制；
- 该波次的玩家锁/遮罩仍按 `spawner.regionId` 计算；
- 这是配置错误，测试时看 error 日志。

### 14.4 `regionId = 0` / 找不到区域

- 打印 error；
- 不加组件；
- 该波次没有有效激活区域，玩家不锁；
- 需要检查 `Spawner.xlsx` 和地图区域 ID。

### 14.5 激活/解锁时机

- 激活区域跟当前 `spawnerIndex`；
- 当前 spawner 清完后不立刻解锁，保持到下一波 spawner 真正生成；
- 这样做是为了避免清完到下一波之间的一帧空隙让玩家滑出边界；
- 关卡结束时 `spawnerIndex` 超出范围，区域清空。

### 14.6 玩家锁只在本客户端

- 没有 `EmitInputSystem` 校验；
- 其他客户端玩家异常走出去，本客户端照常显示；
- AI 看不到区域外玩家；
- 这是按需求接受的“客户端隔离”。

### 14.7 MapEditor 区域列表与撤销

- 区域编辑本身不做撤销；
- `MapSnapshot` 包含区域列表，保存/加载/导出会保留；
- 现有地图撤销/重做在捕获快照时也会带上区域列表，后续地图撤销可能把区域恢复成快照时的状态；
- 如果觉得干扰，可在区域编辑时清空撤销历史或把区域排除出撤销快照，当前未做。

### 14.8 MapEditor 区域越界

- 行内会显示“越界”红字；
- **不会禁止导出**；
- 导出前只强制校验重复 ID；
- 越界区域需要人工修正。

### 14.9 MapEditor 面板形态

- 当前是 `OnGUI` 简易面板，左上角“区域配置”按钮；
- 没有做拖拽矩形、没有做区域撤销；
- 可能和现有 UGUI 面板位置重叠，需要按实际界面调整位置/样式；
- `BlocksInput` 已接入鼠标/触摸输入屏蔽。

### 14.10 区域遮罩

- 每个区域一个矩形 quad；
- 排序 `30000`，覆盖地图和角色，位于 UI 之下；
- alpha `0.12`，闪烁 0.3 秒，冷却 0.45 秒；
- 只闪当前激活区域；
- 只对本地主控玩家触发；
- 同一时间只保留一个闪烁实例，连续触发会被冷却限制；
- 如果实际效果太亮/太暗，调 `RegionMaskManager.cs` 常量。

### 14.11 AI 全局缓存

- `AIAtkGridSystem` 仍按全图所有英雄计算攻击格；
- `AtkBrickSystem` 仍按全图砖块计算；
- 使用处（`AttackLogic.CanAtkPlayer`、`CanAtkPlayerConditional`、`GridConditional`）已经按区域过滤；
- 正确性满足，但性能收益没有完全拿到；
- 后续可做按区域缓存/按 AI 区域重算。

### 14.12 DoorArr

- `doorArr` 逻辑没有改；
- 区域地图如果配置了真实 Door，仍会挡路；
- 2002 的 `doorArr` 为空，无影响；
- 以后要做区域地图时，需要单独决定是否忽略/清除 Door。

### 14.13 Boss 召唤物

- `RegionLogic.InheritRegion` 已预留；
- 当前代码没有独立召唤物创建入口；
- 以后新增召唤时必须调用，否则召唤物没有区域限制。

### 14.14 其他位移

- 弹簧、滑行、分身、推泡、复活、传送目前没有区域判断；
- `RegionLogic` 顶部有 TODO；
- 探险模式当前不会出现这些功能，后续补。

### 14.15 玩家技能

- 玩家目前没有技能；
- `SeekEntity_Player` 已做成可选区域参数；
- 玩家技能调用传 `null`，允许选区域外目标；
- 未来接入时不要默认给玩家加区域过滤。

### 14.16 录像

- `RegionComponent` 是新组件，Entitas 会自动生成快照 Codec；
- 需要实测录像中途恢复：
  - `RegionComponent` 恢复；
  - `SpawnerInfo.cleared` 恢复；
  - 区域锁/解锁正确；
- 区域矩形来自地图静态配置，不进快照。

### 14.17 配置/AB

- 地图 bytes 和 `SpawnerRawConfigList.bytes` 都要重新导出；
- 客户端要重新打 AB；
- 只改 Excel 不发包，客户端不会生效。

### 14.18 编译验证

- `MapEditor/Assembly-CSharp.csproj`：0 error；
