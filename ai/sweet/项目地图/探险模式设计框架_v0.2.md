## 0. 一句话定位

**地图是固定的，build 是随机的。**

玩家用探险等级、材料、护符做长期养成；每局进一张由地图编辑器配置好的固定地图，靠怪物/砖块/宝箱/Boss 随机掉落的遗物和道具组合出不同打法。没有随机房间、没有三选一、没有局内商店和金币。

## 1. 五条设计原则

1. **地图固定，掉落随机**：变化来自 build 和特殊泡，不来自地图结构。
2. **永久进度买“宽度”，不买“高度”**：等级主要解锁地图、道具池、带入槽位；永久战力占比控制在 30% 以内。
3. **惊喜只在局内**：第二条命、无限成长、彩虹箱这类道具只能随机掉，不能合成、不能带入。
4. **没有选择界面，就用“权重 + 保底”让 build 成型**：不能三选一，就必须让掉落跟着玩家已有的标签走，避免整局拿不到能用的东西。
5. **单局短、失败有补偿、组队有分工**：一张图 5-10 分钟，失败保留部分材料/经验。

## 2. 三层进度

| 层 | 提供什么 | 不提供什么 |
|---|---|---|
| **探险等级（1-30）** | 解锁章节/地图/难度/道具进池/带入槽位 | 大量攻击、血量，直接碾压旧图 |
| **材料 + 合成** | 做消耗品/护符、把新遗物解锁进随机池、外观 | 无限叠数值、无限囤药 |
| **单局随机掉落** | 遗物、特殊泡、局内道具、标签 combo | 被账号等级完全覆盖 |

关键连接：**材料合成 = 把新遗物解锁进掉落池**。刷材料不是单纯堆数值，而是拓宽以后每局能掉到的 build 池。

## 3. 单局流程

```
大厅 → 选地图/难度 → 配装（护符 1-3 + 消耗品 1-3）→ 进入地图 →
清怪 / 拆砖 / 捡遗物 / 打精英 / 打 Boss → 结算（评分、材料、经验、解锁）
```

- **一张地图 = 一关**，5-10 分钟；章节只是地图分组，不强制连战。
- 地图由地图编辑器配置：出生点、怪物波次、精英点、砖块、材料点、宝箱、Boss、时间限制。
- 没有随机房间、没有分支路线、没有商店、没有金币。
- 死亡：进入“倒地”，队友救援 3 秒；全员倒地或超时则失败。
- 失败保留 **30%-50%** 材料与经验。
- 结算评分：S/A/B/C，按通关时间、倒地次数、消耗品使用、击杀率计算；评分影响材料倍率。

### 4.3 等级给什么

**推荐：等级只给容错和内容，不给输出。**

- 10/20/30 级：最大生命 +1（基础 6 → 9）。
- 1/10/20 级：护符槽 +1（最多 3）。
- 3/9 级：消耗品槽 +1（最多 3）。
- 5/16/24 级：泡魂槽 +1（最多 3，只有 1 个生效，进图前切换）。
- 其余等级：解锁地图、难度、图鉴、掉落加成。

如果玩家反馈“升级没感觉”，再加一条小天赋树：每级 1 点，三系（火力/生存/拾取），每点 +1%-2%，总上限不超过 15%。

### 4.4 满级后

- 探险等级转“探险声望”：每 1 万经验 1 级，只给称号/外观/周常宝箱。
- 主目标转为：图鉴收集、护符搭配、材料刷取、速通/无伤称号。
- 不做赛季重置、不做每日种子，保持固定地图的轻量结构。

## 5. 掉落系统

### 5.1 材料分级

| 等级 | 名称 | 主要来源 | 用途 |
|---|---|---|---|
| T1 | 糖屑 | 小怪、砖头、普通宝箱 | 基础消耗品、低级合成 |
| T2 | 糖晶 | 精英、Boss、宝箱 | 中级消耗品、图鉴解锁 |
| T3 | 彩虹糖 | 精英低概率、Boss、首通 | 高级消耗品、护符、图鉴 |
| T4 | 星糖 | Boss 低概率、周常、满级宝箱 | 顶级护符、外观、复活币 |

材料保持 **4 种**，不要每个地图一种；地图差异用掉落倾向表达，避免货币爆炸。

### 5.2 单图掉落期望

按 25 个小怪、30 块砖、4 个精英、2 个宝箱计算；Boss 图额外加 Boss 掉落：

| 来源 | 掉落 |
|---|---|
| 小怪 | 40% T1×1；5% T2×1 |
| 砖头 | 25% T1×1；3% T2×1 |
| 精英 | 100% T2×1；15% T3×1 |
| Boss | 100% T2×2；50% T3×1；8% T4×1 |
| 宝箱 | T1×1-2；T2×1 |
| **单图合计** | **T1 ≈18，T2 ≈8，T3 ≈0.8，T4 ≈0.08** |

- 难度倍率：普通 ×1.0、困难 ×1.4、噩梦 ×2.0、深渊 ×3.0。
- 组队：个人掉落；2 人 85%，3-4 人 75%，鼓励组队但不制造“必须 4 人”的压力。
- 保底：连续 3 个 Boss 无 T3，下一个 Boss 必出；连续 10 个 Boss 无 T4，下一个 Boss 必出。
- 首通：每个地图/难度首通额外 T3×2、T4×1。

### 5.3 遗物掉落（随机 build 的核心）

**没有三选一，所有遗物直接掉在地上，走过拾取。**

| 来源 | 遗物 |
|---|---|
| 每张图第一个精英 | 必掉 1 个遗物 |
| 精英 | 60% 掉 1 个 |
| Boss | 必掉 2 个，其中至少 1 个史诗 |
| 砖头 | 6% 掉 1 个 |
| 宝箱 | 必掉 1 个 |
| 单图合计 | 约 5-8 个遗物 |

稀有度：普通 60%、稀有 25%、史诗 12%、传说 3%。Boss 的第 2 个遗物保底史诗；传说受保底控制（见 5.4）。

### 5.4 没有三选一，怎么保证 build 成型

这是去掉三选一后最关键的设计。用 **“标签权重 + 保底 + 重复转化”** 代替选择：

1. **首件定流派**：本局捡到的第一件遗物，决定“本局主标签”（爆/分/火/冰/踢/盾/召/速）。
2. **同标签加权**：之后掉落时，主标签权重 +30%；已经凑到 3 件同标签，+60%；6 件，+100%。
3. **核心保底**：如果第二个精英前还没掉到主标签的核心遗物，下一个精英必掉主标签核心。
4. **史诗保底**：如果前两个精英都没掉史诗，第三个精英必掉史诗。
5. **传说保底**：连续 5 张图没掉传说，下一张 Boss 必掉传说。
6. **重复转化**：重复的规则类遗物自动转成 T2 材料；数值类遗物可叠到 3 层，再重复转材料。
7. **标签套装**：同标签 3 件/6 件触发套装效果（见 6.3），让“没得选”也能形成明确 build。
8. **保底不跨局**：以上保底按单局/单图计算，避免长期积累后每局都爆传说。

### 5.5 材料消耗口

1. 合成消耗品/护符（主消耗）。
2. 解锁图鉴：把新遗物加入掉落池（长期目标）。
3. 外观/称号（T4）。
4. T4 兑换指定护符/皮肤（大厅功能，不产出金币）。

不要做“装备修理”，只会让玩家烦躁。

### 6.4 特殊泡泡（每 5 个泡泡触发）

**机制**：

- 每成功放 1 个泡泡，充能 +1；满 5 个，下一个泡泡变特殊泡，充能归零。
- 特殊泡使用独立泡泡 ID（建议 210001 起），随 `BombKey` 一起下发，保证各端生成同一种泡。
- 特殊泡继承玩家当前的泡泡数/威力/速度，不额外占泡泡上限，可被踢。
- 特殊泡效果由“当前生效泡魂”决定；没有泡魂时默认“爆裂泡”（半径 +1）。
- 充能跨地图保留（如果连战）/新一局清零；死亡不掉充能。
- UI：5 个充能点 + 特殊泡皮肤 + 触发时短特效。

**推荐 8 个特殊泡**（首版选 6 个）：

| 名称 | 标签 | 效果 | 数值 |

| 燃烧泡 | 火 | 爆炸后留火 | 3 秒，每秒 1 伤害 |
| 冰冻泡 | 冰 | 冻结敌人 | 2 秒（Boss 1 秒），不造成伤害 |
| 磁力泡 | 控 | 把敌人拉向爆心 | 2 格内拉 1-2 格，伤害 1 |

### 6.5 角色光环（角色专属）

#### 6.5.1 已确定规则

- **形状**：菱形，`|dx| + |dy| <= R`，以角色当前 `GridID` 为中心。
- **来源**：角色专属，一个角色一个标志性光环；护符、遗物、泡魂不新增光环。
- **触发**：只做被动/周期，不做主动技能；首版没有按键释放。
- **目标**：友方英雄（含自己），首版不含分身/宠物；敌方减益类单独标记。
- **施法者状态**：存活或 `TryTrapped` 时生效；被困、倒地、死亡时停止，恢复后继续。
- **首次触发**：进图后 2 秒；之后每隔 `intervalSec` 秒触发一次。
- **预警**：触发前 0.5 秒地面显示菱形预警圈；首版可只做触发瞬间特效。
- **UI**：地面菱形范围、角色头顶图标、友方 buff 图标 + 剩余时间。

#### 6.5.2 叠加与上限

- **同名光环只生效一个**，取最高值，刷新持续时间，不叠加。
- 不同名光环可以叠，但受以下上限：
  - 速度总加成 ≤ **+30%**（或 +2 速度档）。
  - 威力总加成 ≤ **+2**，且不超过 9。
  - 泡泡总加成 ≤ **+2**，且不超过 8。
  - 护盾最多 **1 次**（刷新不叠加）。
  - 治疗每次脉冲最多 **1 HP**。
  - 特殊泡充能不超过 **5**。
- 控制类对 Boss 效果减半或免疫，精英 75%。
- 同队重复角色：休闲允许，但第二个同名光环只显示“重复，不叠加”；高难/排位建议禁止重复角色。

#### 6.5.6 落地注意

- 新增 `AdventureAuraSystem`，放在 `NetSyncLogicSystems` 的 buff 系统之后；用 `GameTime` + `FixTimer` 驱动，不用 `Time.deltaTime`。
- 菱形判定用整数格坐标：`|dx| + |dy| <= radius`；只遍历英雄数组，人数很少，不需要空间索引。
- 速度不要直接复用 `BuffSpeed`：现有 `BuffSpeedSystem` 会移除减速/西瓜皮，容易变成“加速光环附带净化”。建议新增倍率型 `BuffAuraSpeed`，在 `CommonLogic.UpdateRoleSpeed` 里乘算。
- 新增通用 `AuraBuffComponent { auraID, effectType, value, endTime, sourceUID }`，由各 buff 系统读取；避免为每种效果加一个组件。
- 光环由角色配置决定，不需要新协议；开局同步 roleID 即可。各端用同一份配置和同一个 `GameTime` 自行推导，保证一致。
- 光环判定用同步后的 `GridID`；本地主控玩家贴边时允许 1 帧容差（用预测位置辅助判断），避免加速时有时无。
- 录像快照需要包含 `AuraBuffComponent`，否则中途恢复会丢光环状态。
- 分身首版不吃光环；后续如果要吃，配置 `affectClone = true`，并单独调数值。

### 6.6 格子计数：冲刺

用现有 `RoleCounterGridComponent` 做第二个表达：

- 每移动 **20 格**获得 1 层“疾风冲刺”，最多 2 层。
- 冲刺：向当前方向瞬移 2 格，0.3 秒无敌，不能穿墙。
- 冲刺不消耗泡泡，不触发特殊泡充能。
- 作用：给走位操作空间，也让“移动”类遗物有价值。

### 6.7 落地注意（现有代码）

- `EmitInputSystem.cs:329-332` 有一个明显笔误：格子变化时写的是 `ReplaceRoleCounterBomb(GetRoleCounterGrid().count + 1)`，应该更新 `RoleCounterGrid`，否则格子计数永远不增长，还会污染泡泡计数。
- `SkillSystem.cs:31-46` 现在把两个计数每 5 次拿来触发一次飞镖伤害（测试逻辑），正式做探险时建议替换成独立的 `AdventureCounterSystem`。
- 两个计数器目前是“第一次用到才 Add”，没有在角色生成时初始化，也没有在死亡/新图时重置；需要补 `AddRoleCounterBomb(0)` / `AddRoleCounterGrid(0)` 和重置规则。
- `Bomb.xlsx` 里 `200011` 的 `bombType` 当前是 5，而代码 `FootballLogic` 按 `Football_Normal(4)` 判定计数球；落地前先核对配置与枚举。
- **特殊泡类型必须随 `BombKey` 下发**（现在 `BombKey` 只有 grid + createTime）。否则本地放了特殊泡，别的客户端只会按默认泡泡生成，效果不一致。建议加 `bombID` 字段。

### 7.2 图鉴解锁

- 每解锁一个遗物，它就加入掉落池；池子越大，build 越丰富。
- 图鉴收集度只给便利：材料掉落 +1%、遗物品质权重微调、图鉴展示；不给攻击力。
- 满图鉴给称号/皮肤，不给战力。

## 8. 地图与关卡（替代随机房间）

既然地图由地图编辑器固定，设计重点从“生成”转到“地图配置规范”。

### 8.1 一张探险地图需要配什么

| 配置项 | 说明 |
|---|---|
| 章节 / 难度 | 决定解锁等级、掉落倍率 |
| 推荐等级 | 低于推荐等级 5 级时提示 |
| 时间限制 | 5-10 分钟；超时失败 |
| 出生点 | 1-4 人，按人数分点 |
| 怪物波次 | 刷怪点、怪物池、数量、间隔；可固定可随机池 |
| 精英点 | 2-5 个；第一个精英必掉遗物 |
| 砖块 | 数量、布局、材料掉落表 |
| 宝箱 | 1-3 个；必掉 1 个遗物 |
| Boss | 可选；Boss 图必配 |
| 材料倾向 | 本地图 T1/T2/T3 的额外权重 |
| 首通奖励 | T3/T4、护符、图鉴 |

### 8.2 章节结构建议

- 每章 3-5 张图；最后一张是 Boss 图。
- 普通图：刷材料/遗物，5-8 分钟。
- Boss 图：8-10 分钟，Boss 2-3 阶段。
- 章节之间用等级解锁，不做强制连战。
- 玩家可以重复刷已通关地图，难度可选；高难度提高材料/遗物品质。

### 8.3 地图编辑器需要补的能力

- 刷怪点/波次配置（复用 `Spawner.xlsx` / `Level.xlsx` 的思路）。
- 砖块内材料掉落表绑定。
- 宝箱/精英/Boss 点位。
- 推荐等级/时间限制/首通奖励字段。
- 地图难度覆盖：同一张图普通/困难/噩梦/深渊的怪物数值倍率。
- 预览/校验：出生点可达、Boss 可达、宝箱不被墙封死。

## 9. 数值基线

### 9.1 数值怎么定（三个锚点）

1. **单图时长**：普通 5-8 分钟，Boss 图 8-10 分钟。
2. **击杀时间**：小怪 3-5 秒，精英 15-20 秒，Boss 60-90 秒。
3. **成长曲线**：满级 80-100 图；每图材料够 1-1.5 个消耗品。

公式：

```
敌人 HP ≈ 队伍 DPS × 预期击杀时间
材料产出 ≈ 合成成本 ÷ 期望 farm 图数
升级经验 ≈ 满级总时长 ÷ 单图经验
```

先调节奏，再调数值，最后调经济。一次只动一个旋钮（敌人 HP、玩家 DPS、掉落数量），否则找不到原因。

## 10. 联机细节

- **人数**：1-4 人；单人可玩，4 人加成但敌人 HP 提高。
- **掉落**：个人掉落，不用抢；材料个人；遗物个人（避免抢装备）。
- **复活**：倒地 3 秒救援；每图每人 1 次免费救援；复活币额外一次。
- **友伤**：默认关闭；困难/深渊可开启，给额外奖励。
- **分工**：角色光环 + 遗物标签天然形成输出/控制/辅助/机动；不强制职业。
- **掉线**：AI 托管或保留角色 60 秒；重连回原局。
- **观战**：死亡后可观战，等待队友通关/团灭。

## 11. 防坑清单

1. **没有三选一，最怕“整局抽不到能用的”**：必须做标签权重、核心保底、史诗保底、重复转化；否则玩家会觉得“运气决定一切”。
2. **固定地图容易腻**：靠难度层级、首通奖励、材料目标、图鉴收集、速通称号延长寿命；不要只靠加数值。
3. **永久成长过强**：满级玩家随便过 → 随机失去意义。控制在 30% 以内，靠难度层吸收。
4. **带入道具过强**：带满药水比研究 build 划算 → 玩家停止思考。用槽位、消耗、评分惩罚限制。
5. **单图太长**：超过 10 分钟，QQ堂用户流失 → 先砍波次，不要砍 Boss 机制。
6. **失败太伤**：药水全没、材料归零 → 失败保留 30%-50%。
7. **材料通胀**：只进不出 → 图鉴/护符/外观/周常兑换做消耗口。
8. **新老差距**：老玩家带新玩家碾压 → 等级同步/难度自适应/带新奖励（后续再议）。
9. **配置/枚举不一致**：特殊泡 ID、bombType、掉落表要统一走导表，避免手配漏项。
10. **联机不同步**：特殊泡类型必须随 op 下发，不能各端自己猜；否则同一次放泡在不同客户端是不同效果。
11. **光环叠加失控**：同名只生效一个、速度封顶 +30%、控制类 Boss 免疫；4 人同角色时提示“光环重复”。

## 12. 落地映射（先做最小闭环）

### 12.1 模式入口

- 新增 `MapType.Adventure = 19`（当前 19 空闲；或用 `Cave` 先做原型）。
- 大厅新增“探险”页签：地图、难度、组队、图鉴、合成、等级。
- 服务器 `NormalRoom` 增加探险房间/单人开局；`BattleServer` 仍然只转发 op，不参与战斗模拟。

### 12.2 配置表

优先复用现有表，避免一次加十几张：

| 需求 | 复用/新增 |
|---|---|
| 局内道具 | 复用 `Item.xlsx` |
| 泡泡/特殊泡 | 复用 `Bomb.xlsx`，新增 210001+ |
| 掉落 | 复用 `Drop.xlsx` / `DropBag.xlsx`，新增探险掉落组 |
| 怪物/Boss/波次 | 复用 `Boss.xlsx` / `Spawner.xlsx` / `Level.xlsx` |
| 地图 | 复用 `MapInfo.xlsx`，新增探险字段或 `AdventureMap.xlsx` |
| 等级/材料/合成 | 新增 `AdventureLevel.xlsx`、`AdventureMaterial.xlsx`、`AdventureCraft.xlsx` |
| 遗物/护符/泡魂 | 新增 `AdventureRelic.xlsx`、`AdventureKeepsake.xlsx` |
| 角色光环 | 新增 `AdventureRoleAura.xlsx`；`Role.xlsx` 增加 `auraID` 字段 |
| 地图掉落倾向 | 新增 `AdventureMapDrop.xlsx`，或在 `MapInfo` 加字段 |

### 12.3 客户端系统

| 系统 | 职责 |
|---|---|
| `AdventureRunSystem` | 单图状态：难度、时间、评分、结算 |
| `AdventureDropSystem` | 材料/遗物掉落、标签权重、保底、重复转化 |
| `AdventureCounterSystem` | 泡泡/格子计数、特殊泡、冲刺 |
| `AdventureLoadoutSystem` | 带入护符/消耗品、使用与消耗 |
| `AdventureCollectionSystem` | 图鉴、解锁、套装展示 |
| `AdventureAuraSystem` | 角色光环：周期触发、菱形范围、友方/敌方效果、上限 |

复用：`SpawnerSystem`、`AILogicSystems`、`RoleKickBombSystem`、`BombMapRulesSystem`、`ItemPickUpSystem`、`ReplaySnapshot`。

不需要：`AdventureShopSystem`、`AdventureRewardChoiceSystem`、`AdventureRoomSystem`。

### 12.4 协议

- `BombKey` 增加 `bombID`（或 `specialBombID`）：特殊泡必须随 op 下发。
- 角色光环由角色配置决定，不需要新 op；开局同步 roleID（或 auraID）即可，各端用同一份配置和 `GameTime` 自行推导。
- 房间开局增加 `AdventureLoadout`（护符/消耗品/难度/seed）。
- 结算增加 `AdventureResult`（评分、材料、经验、解锁）。
- 掉落如果由客户端模拟，需要把“掉落结果”纳入可复现逻辑；建议掉落走确定性随机（服务器 seed + 局内计数），避免各端不一致。

### 12.5 服务器

- `DataServer` 新增 `AdventureDb`：等级/经验/材料/图鉴/护符/消耗品。
- `LoginServer` 新增探险入口、配装校验、结算发放。
- 结算校验：最短时长、击杀数上限、材料/小时上限、seed 一致性；PvE 比 PvP 更容易被刷，必须做基础风控。

## 13. 首版 MVP 建议

不要一次做完整 30 级 + 9 张图 + 100 遗物。建议第一版：

- **3 张图**：2 张普通图 + 1 张 Boss 图。
- **等级 1-10**（先验证曲线）。
- **3 种材料**（T1/T2/T3）。
- **10 个遗物、4 个特殊泡、6 个消耗品、2 个护符**。
- **4 个现有角色各 1 个光环**（火力/疾风/回春/糖盾），只做被动/周期，不做主动技能。
- **1-2 人**先跑通，再扩 4 人。
- **不做**图鉴扩容/外观/周常/4 人/深渊，只验证：
  - 单图时长
  - 通关率
  - 第二局开启率
  - 材料/图
  - 等级速度
  - 没有三选一时 build 是否能成型

跑通后再加：更多地图、4 人、图鉴、护符、深渊。

## 14. 待确认

**已确定（2026-10-23）：**

- 光环形状：菱形，`|dx| + |dy| <= R`。
- 光环来源：角色专属，一个角色一个标志性光环。
- 首版不做主动技能，只做被动/周期光环。

**剩余问题：**

1. 一张探险地图是一关（5-10 分钟），还是希望一张图里分多段？这决定结算和难度节奏。
2. 单图目标时长是 5-8 分钟还是 8-10 分钟？
3. 永久成长接受“只解锁、不加攻击”吗？还是必须要有等级属性？
4. 材料是否可交易/售卖？如果可交易，经济系统要另做一套。
5. 首版美术能做多少：**4 个特殊泡 + 10 个遗物 + 3 张图**，够不够撑 MVP？
6. 现有足球 PvE（1217/1218）是并入探险，还是保持独立？
