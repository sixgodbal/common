# 客户端功能模块（Unity）

## 基础信息

- 客户端工程：`D:\sixgod\gitproject\test\Code\Demo`
- Unity 版本：`2022.3.27f1c1`
- 语言/架构：C#，战斗基于 Entitas ECS，UI 使用 UGUI，渲染使用 URP。
- 协作约定：只提交 `Assets/` 下内容；移动或重命名 Unity 资源时保留 `.meta`。

## Assets 目录地图

| 目录 | 主要用途 |
|---|---|
| `Assets/Scripts` | 运行时代码主目录 |
| `Assets/Editor` | 编辑器工具、打包入口 |
| `Assets/Data` | 美术/资源原始数据，含导出的 `Xls` 二进制 |
| `Assets/Configs` | 运行读取的表情/即时配置 bytes |
| `Assets/Resources` | 常驻资源、ABMD5、版本号、场景等 |
| `Assets/StreamingAssets` | 随包原始资源，主要是批量资源文件 |
| `Assets/Plugins` | 第三方原生插件与 DLL |
| `Assets/Libraries` | Entitas、Spine、DesperateDevs 等库 |
| `Assets/Sources/Generated` | Entitas/Jenny 生成代码，勿手改 |

## 常用构建命令（来自仓库文档）

- 打开工程：`Unity.exe -projectPath ..`
- 标准包：`Unity.exe -batchmode -projectPath .. -executeMethod BuildApp.Build -quit`
- 仅 AB：`Unity.exe -batchmode -projectPath .. -executeMethod BundleEditor.NormalBuild -quit`
- EditMode 测试：`Unity.exe -batchmode -projectPath .. -runTests -testPlatform EditMode ...`
