# 《果糖星球》提示词包 v2（可直接复制使用）

> 用途：不依赖本机模型，任何支持图生图 / 文生图的工具都能用（即梦、可灵、Midjourney、Nano Banana、豆包、Seedream）。
> 用法：`[STYLE]` + 需要的 `[CHAR-xx]` + 该镜头的画面描述。**三段拼在一起，不要改前两段的措辞。**
> v2 变更：STYLE 与 CHAR 块全部按 `角色参考\` 四张定稿立绘重写，详见 `角色定稿_立绘基准_v3.md`。旧措辞作废。

---

## 0. 拼装规则（最重要）

```
[STYLE] 保持不变
[CHAR-xx] 只挑这一镜出场的角色，其余删掉
镜头描述 只写「画面里发生什么」，不写风格词
```

**铁律**
1. 同一个角色，永远用同一段 `[CHAR]`，一个字都不改。
2. 先出角色立绘，再用立绘当参考图（image reference）出镜头。
3. 一次最多 3 个角色同框，第 4 个用前景遮挡或干脆不入画。
4. 固定 seed（如果有这个功能），风格和脸会稳很多。
5. 出图后只挑「脸对、构图对」的，细节后期修。

## 5. 一致性 Workflow（推荐顺序）

1. **先出 4 张角色立绘**：`[STYLE] + [CHAR-xx] + "full body character sheet, front view, neutral pose, plain light background"`
2. **人工挑脸**：选最像原图的，存成 `ref_角色名.png`
3. **出镜头**：`[STYLE] + [CHAR] + 镜头描述`，并且把 `ref_角色名.png` 作为参考图传入
4. **批量时只改镜头描述**，风格段和角色段一个字都不动
5. 同框镜头出现「脸合并」时，改成 3 人 + 1 人前景遮挡

## 6. 让画面动起来

### 视差（文戏用）
把图拆成 4 层：前景草叶 / 角色 / 中景树干 / 远景光斑。AE 或剪映里给每层不同位移速度，2 秒就能有「镜头在动」的感觉。

### 图生视频（武戏用）
只需要这 5 个镜头：
- 2-1 白光柱（光在扩散、鸟群飞出）
- 7-3 金瞳同时亮起（依次点亮）
- 8-1 逃跑（横向跟拍 + 扬尘）
- 9-1 巨蟒探头（缓慢下压 + 像素抖动）
- 10-2 尾巴横扫（横扫 + 画面失焦）

图生视频提示词模板：

```
camera slowly pushes in, the subject barely moves, subtle parallax on the
background layers, 2.5D paper-cutout animation, 24fps, no style change,
no morphing faces, no extra limbs
```
