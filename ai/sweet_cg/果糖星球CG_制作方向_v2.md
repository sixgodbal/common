# 《果糖星球》1 分钟 CG 短片 · 制作方向 v2

> v2 变更：角色设定部分**全部依据提供立绘重写**；风格锚点改为「日系 Q 版立绘」；新增巨蟒升级方向。
> 规格：16:9 / 1920×1080 / 24fps / 69s / 26 个镜头。

---

## 1. 一句话视觉定位

四个水果小人从「客厅糖水日常」一路走进「丛林深处的白色禁区」，
直到画面被白光吞掉。

三个关键词：**扁、糖、萌**（v2 修正：**扁** = 日系 Q 版平面化，不做 3D 体积）。
- **平面化**：角色像被剪下来贴在背景上，阴影只做 2–3 阶色块，不做写实高光和体积渐变。
- **糖**：高饱和糖果色，材质像软糖、糖纸、硬糖。
- **萌**：恐怖不靠獠牙，靠**眼睛 + 体型差 + 声音**。

## 2. 美术风格规范（以提供立绘为唯一标准）

### 2.1 渲染规则
| 项目 | 规范 |
|---|---|
| 整体 | 日系 Q 版赛璐璐，高饱和，暖调，人物头身比约 1:3 |
| 阴影 | 2–3 阶色块 + 边缘柔和高光；**不做**写实环境反射、次表面散射 |
| 描边 | **中粗深色描边**（桑 / 莓偏紫褐，卡布拉偏橄榄褐，小不甜偏深紫）；白色粗贴纸边只用于**宣传图 / 特写插入镜头** |
| 材质 | 头发高光画成「糖果光泽」的弧形色块；服装布料不画织纹，用色块概括 |
| 透视 | 弱透视，接近正交；场景像多层剪纸叠起来 |
| 角色动作 | 由图生视频驱动，保持 Q 版块状节奏；动作幅度可以大，但不做写实关节、不做 3D 转身 |
| 禁止 | 3D 渲染质感、PBR 材质、真实皮肤质感、写实毛发 |

### 2.2 场景分层（做动态的关键）
每个场景拆 4 层，后期做视差就有「在动」的感觉：
前景（草叶 / 沙发扶手 / 树叶）→ 角色层 → 中景（墙面 / 树干 / 灌木）→ 远景（天空 / 光斑 / 雾）。

### 2.3 镜头语言
- **日常段**：固定机位 + 极缓推，笑点用 snap zoom。
- **惊悚段**：机位压低、变仰，加暗角，推镜变慢。
- **逃跑段**：横移跟拍 + 速度线 + 手持微抖。
- 全片只允许 **1 次慢镜**（蛇尾横扫）。

### 2.4 色彩脚本
| 段落 | 时间 | 主色 | 情绪 |
|---|---|---|---|
| 客厅 | 0:00–0:11 | 奶油白 + 芒果黄 + 粉（暖） | 安全、热闹 |
| 白光 | 0:11–0:23 | 薄荷绿 + 过曝纯白 | 好奇、神秘 |
| 出发 / 春游 | 0:23–0:41 | 鲜绿 + 柠檬黄 + 天空蓝（暖） | 欢快、上扬 |
| 黄昏过渡 | 0:41–0:45 | 金橙 → 深蓝紫，暖光收束 | 暖意消退、预感 |
| 阴森 | 0:45–0:57 | 墨绿 + 冷蓝紫，饱和度降 30% | 不安 |
| 蛇 | 0:57–1:07 | 深紫黑 + 金瞳 + 血橙反光 | 恐惧 |
| 白屏 | 1:07–1:09 | 纯白 + 深紫字 | 留白 |

> 饱和度 90% → 20%，最后 2 秒猛拉 100% 纯白。刺眼的那一帧，就是尾巴命中的那一帧。

### 3.1 桑小墨（男）· 桑葚
- **外观**：深棕近黑（偏灰紫）的蓬松碎发 + 一根粗的豆芽状**呆毛**；皮肤苍白、腮红明显；**半睁的深蓝色眼**，眼尾下垂，自带「厌世」感。
- **服装**：宽松白衬衫 + **大号黑色缎带蝴蝶结**；深藏青**高腰短裤**（两颗金扣、金色包边）；光腿 + 黑色圆头小皮鞋。
- **轮廓记忆点**：呆毛 + 大黑蝴蝶结。
- **身高**：与卡布拉**同一档**，视觉上略矮半头。两人靠发型和道具区分，不靠身高。
- **定稿依据**：`角色定稿_立绘基准_v3.md` §2（马甲设定已作废）。
- **数据卡**：糖泡 3 / 威力 1 / 速度 **5**
- **身份**：暂缺（只有外形和数值，需要补）。
- **性格**：全队最快的腿，也是最怂的人；话少、吐槽精准，遇事第一个跑但会回头喊人。
- **声音**：低沉少年音，语速慢，句尾下沉。
- **动作标签**：抱臂、拽领结、呆毛竖起来（恐惧可视化）。

### 3.2 小不甜（女）· 山竹
- **外观**：深紫近黑短蓬发（发梢外翘），**红瞳**大眼睛，立绘是面无表情的冷淡脸；两侧是**银白色玫瑰状发饰**（对应山竹的白色果肉），头大、腿短，全队最矮。
- **服装**：**无袖连衣裙**——白色大花瓣状翻领（像山竹果蒂）+ 深紫黑贴身胸衣 + 白 / 灰蓝及膝大裙摆；**赤足**（立绘基准）。
- **配色逻辑**：深紫发色（山竹外壳）+ 白色裙摆（山竹果肉）= 一眼认出是山竹精灵。银白玫瑰发饰是全队最好认的头部符号。
- **轮廓记忆点**：两侧银白发饰 + 白色大领 + 全队最矮。
- **定稿依据**：`角色定稿_立绘基准_v3.md` §3（淡紫薄纱、蕾丝、过膝袜、小皮鞋设定全部作废）。
- **数据卡**：糖泡 2 / 威力 1 / 速度 4
- **身份**：**果糖星球第一个诞生的水果精灵**，由山竹进化而来，凝聚星球精华，被称为「星球的亲女儿」。天生果糖之力精纯，**唯一能用双发糖泡**，速度潜质卓越。
- **性格（重要修正）**：设定上是**天真、笑起来甜甜**的小孩，和立绘的放空脸是反差。表演按「天然呆 + 慢半拍的笑」处理——不是高冷，是没反应过来。
- **声音**：清亮少女音，语速慢半拍；开心时尾音上扬。
- **动作标签**：发呆、突然回神、踮脚看远处、笑起来眼睛弯成月牙。

### 3.3 卡布拉（男）· 杨桃（金发探险系）
- **外观**：**奶油黄到金黄的星形刺猬头**（大块尖刺）+ **额头护目镜**（深棕皮带、淡蓝镜片）；**白皙皮肤**（不要小麦色、不要偏黄），绿色笑眼，咧嘴**露出一整排牙、没有獠牙**。
- **服装**：橄榄卡其无袖探险背心 + 绿色领巾 + **棕色背包**（包顶一卷地图/铺盖）；绿色腰带 + 金扣；腰侧挂**金黄星形果片挂饰**；棕色灯笼裤 + 深棕长靴（绿色交叉绑带）。
- **身高**：与桑小墨同一档，**视觉略高半头**，肩更宽。
- **轮廓记忆点**：星形金发 + 护目镜 + 背包。
- **定稿依据**：`角色定稿_立绘基准_v3.md` §4（小麦色、小尖牙、黄铜望远镜设定作废）。
- **数据卡**：糖泡 1 / 威力 1 / 速度 4
- **身份**：出身**机械工业家族**，家族参与过果糖星球初创期的建设。长辈带回的见闻让他对「探索」的欲望超过修行，**至今只能用单发糖泡**（和糖泡 1 对上了）。
- **性格**：自封队长，嗓门最大、胆子最小；负责提出「我们去看看」。
- **声音**：元气少年音，爱拖长音。
- **动作标签**：叉腰、拉下护目镜（出发仪式）、举地图卷远望、被吓到时整个人拍扁。

### 3.4 莓洛蒂（女）· **草莓**（贵族千金）
- **外观**：深棕色齐刘海 bob（发尾内扣），狭长的**青绿色眼睛**，自信小微笑；头戴**白色蕾丝半圆头饰**（边缘珍珠点）+ 白花（黄心）+ 青绿缎带结；耳侧小耳坠。
- **服装**：**树莓质感披肩式泡泡袖**（深红→亮红渐变，圆润果粒 + 白色小籽点）+ 黑色胸衣 + 白色心形胸板（青绿枝叶胸针 + 白坠珠）+ **树莓红前开衩短裙**；**赤足**（立绘基准）。

### 3.6 糖泡设定（决定战斗与笑点）

| 角色 | 糖泡 | 说明 |
|---|---|---|
| 小不甜 | **双发** | 唯一能双发，天生果糖之力精纯 |
| 桑小墨 | 3 格 | 数值最高，但威力 1 |
| 莓洛蒂 | 3 格 | 威力全队最高（2） |
| 卡布拉 | **单发** | 心思全在冒险，几乎没进步 |

> 剧情用法：卡布拉嘴上吹自己厉害，实际只能打一发；小不甜能双发却常常在发呆。**反差就是笑点。**

### 3.7 巨蟒 · 升级方向（两套方案）

**现状**：像素风紫色蛇头，金色大眼，粉舌头，圆钝可爱。

**方案 A（推荐）· 像素即「世界的 bug」**
> 果糖星球是高清高饱和的糖果世界，而从白光里出来的东西，是**低分辨率的**。
> 它不属于这个世界，所以它连像素都是「错的」。

- 保留像素风，但**像素块放大 4–8 倍**（越近越糊，压迫感来自「看不清」）。
- 配色压暗：紫黑 + 瘀伤青紫，取消可爱的粉色舌头，改成深红分叉信子。
- 眼睛：金色 → **暗金竖瞳 + 血红外圈**，眼角带像素化的「故障抖动」。
- 恐怖点：像素边缘掉帧、扫描线闪烁、颜色错位 —— 像信号不好的画面。
- 好处：和现有素材零冲突，越粗糙越吓人，而且**观众会猜到白光和它有关**。

**方案 B · 2D 重绘**
保留紫金配色和圆钝嘴型，重绘成 2D 立绘，加鳞片裂痕、眼周阴影、獠牙只露一点点。
> 更「正常」，但丢掉了像素这个记忆点。

**两套方案的共同底线**：不出现口腔内部、不做撕咬、不做血浆。凶狠靠**眼睛、体型差、沉默**。

#### 眼睛的归属（重要，别再画错）

镜头 **7-1 / 7-3** 里出现的所有眼睛，都是**蛇的眼睛**，不是别的生物。

| 项目 | 规定 |
|---|---|
| 瞳孔 | **竖瞳**，杏仁形眼裂 |
| 虹膜 | 金黄，外圈一道极细的血红边 |
| 眼部结构 | 眼上方有鳞片状的**角质眉骨**隆起 |
| 头部 | **楔形、扁平**，大半融进黑暗，只看得见轮廓和眼睛 |
| 禁止 | 猫耳、圆脸、毛茸茸的小动物、猫头鹰式圆眼、任何外耳 |

> 一句话判据：**只要画出了耳朵，就是错的。** 蛇只有眼和信子，没有耳廓。

> 铁律：同一角色、同一段描述、同一次措辞。换词就换脸。

### 阶段 3 · 让画面动起来（已定：方案 B 图生视频）

> 纸片人方案（整块变换 + 12fps 抽帧）试片效果不佳，**已弃用**；`tools\paper_anim.ps1` 仅留作参考。

**做法**：每镜用关键帧作首帧，调 Seedance 图生视频，取前 2.5–3 秒进片。

- **固定机位优先**：提示词写死「镜头完全不动、背景静止」，背景锁得最稳；
- 需要跟拍时，写「镜头跟随角色、背景反向移动」，可接受轻微漂移；
- **方向必须写对**：5-1 是向左跑，卡布拉领跑、桑小墨最后；
- 动作要写「步伐加快、弹跳明显、手臂摆动大」，否则模型会演得偏僵；
- 720p 输出统一用 lanczos 升到 1080p；
- 每镜单独出片，剪辑时按节奏表裁切；5 个武戏镜头（2-1、7-3、9-1、10-2、8-1）同样走 B。

**转场**：白闪、特写插入（叹号、眼睛）都用硬切，不做溶接。**唯一例外**：10-2 蛇尾即将命中的最后 1.5 秒开始渐白，直接溶进 11-1 的纯白（用 `tools\make_animatic.ps1 -WhiteFadeShot 10-2 -WhiteFadeDur 1.5` 可复现）。

### 阶段 4 · 剪辑与声音
先卡点粗剪 → 铺音效 → 混音。片长严格控制在 58–62 秒。
