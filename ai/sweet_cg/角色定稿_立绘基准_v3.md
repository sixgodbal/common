### 使用规则（铁律）
1. 角色脸、发、服装、配色以这四张为准；文字描述只是索引，**冲突时以图为准**。
2. 每张新图都附对应立绘作 image reference，`[STYLE]` + `[CHAR]` 措辞不改。
3. 一张图最多 3 个角色，第 4 个用前景遮挡或换镜。
4. 立绘是「正面基准」。侧面 / 背面只在需要时按同一 CHAR 块补出，不做重新设计。
5. 全片不换装。要做变体（换鞋、加外套）先停在 `角色参考` 里另开文件，不覆盖原图。

## 1. 通用立绘规格（所有角色共用）

| 项目 | 标准（对齐四张立绘） |
|---|---|
| 画风 | 日系 Q 版赛璐璐，头身比约 1:2.8–3.0，头大、肩窄、手脚短 |
| 描边 | **中粗深色描边**：桑 / 莓用深紫褐，卡布拉用深橄榄褐，小不甜用深紫；不是细线，也不是白贴纸边 |
| 阴影 | 2–3 阶色块 + 一道暖色边缘光；不做渐层体积、不做环境反射 |
| 肤色 | 统一的奶白肤色 + 眼角/脸颊明显腮红 + 耳廓偏粉 |
| 眼睛 | 大眼、粗上睫线、下眼睑细线、虹膜两段渐变 + 1–2 个白色高光点；**眼下不做写实卧蚕** |
| 五官 | 一个点鼻、一条短线嘴，不做鼻梁阴影 |
| 手 | 三指半简化手（拇指 + 合并的指块），不画指甲 |
| 禁止 | 3D 渲染、PBR、塑料反光、真实皮肤/毛发、写实鼻影、欧美厚涂、白贴纸粗边（贴纸边只用于宣传图） |

### 1.1 风格底块（立绘用，锁定）

```
Japanese chibi anime full-body character illustration, single character,
standing, plain transparent background, thick soft dark line art,
3-tone cel shading with one warm rim light, candy-saturated color palette,
flat 2D look, chunky proportions, big expressive eyes with white highlights,
soft blush on cheeks, no 3D render, no PBR, no realistic skin, no text, no UI
```

### 1.2 通用负面词（在提示词包负面词基础上加）

```
tall slim body, realistic proportions, mature face, thin line art,
white sticker outline, 3d render, plastic toy, glossy 3d, painterly,
extra accessories, redesign, changed outfit, different hair color,
text, letters, UI, stat bar, numbers, watermark, logo
```
