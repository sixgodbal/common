## 工具

| 脚本 | 作用 |
|---|---|
| `tools\render_shots.ps1` | 按批次出关键帧：场景图 + 多张立绘作多图参考，调 Seedream 5.5 |
| `tools\shots_batch1.json` | 1-1 ～ 5-5 的镜头提示词配置（`-Only` 可单镜重跑，`-Force` 覆盖） |
| `tools\shots_batch2.json` | 6-1 ～ 10-2 的镜头提示词配置（含夜色/巨蟒风格覆盖） |
| `shots\_animatic_list.txt` | 按 60 秒节奏表的图片时长清单 |
| `tools\make_animatic.ps1` | 逐图定长重编码成 animatic（`-List` / `-Out` / `-Fps` 可调） |
| `tools\paper_anim.ps1` | （已弃用）纸片人动画试片脚本，仅留作参考 |
| `tools\paper_anim_5-1.json` | 5-1 纸片人测试参数（角色位置、速度、弹跳、lean） |
| `tools\seedance_i2v.ps1` | Seedance 图生视频（首帧驱动） |
| `tools\ark_image.ps1` | 调方舟 Seedream 出图（支持参考图/图生图） |
| `tools\cutout.ps1` | 抠背景，输出透明底 |
| `tools\compose_lineup.ps1` | 多角色按身高拼同框图 |
| `tools\place_chars.ps1` | 把角色摆进场景，生成单帧 |
| `tools\split_lineup.ps1` | 从同框图里切出单个角色 |
| `tools\desaturate.ps1` | 降饱和（不改线条） |
