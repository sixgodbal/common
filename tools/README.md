# 小工具合集

这里存放所有自制小工具。每个工具一个独立子目录，互不依赖，单独拷走也能用。

# 开发测试时，尽量不要把界面弹到最前面（抢前台）

## 目录约定

- 一个工具一个子目录，目录名见名知意
- 每个工具目录自带入口文件、配置文件和 README，不依赖上级目录
- 代码量较大的工具在目录里放一份 `开发文档.md`（结构、关键函数、坑、测试方法），方便下次快速接手
- 新增工具后，在上面的表格里补一行
- 想开机自启或固定到任务栏的，直接对工具目录里的入口文件右键 → 发送到 → 桌面快捷方式
