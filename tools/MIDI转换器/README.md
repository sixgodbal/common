# MIDI 转换器

把 MIDI 文件渲染成 **MP3 / WAV / FLAC / OGG**，也能在这些常见音频格式之间互相转换。
窗口很小（200×200），把文件直接拖进去就能用。

- MIDI → 音频：使用 Windows 自带的 GM 音色库 `gm.dls` 离线合成，不需要装声卡或音源
- 音频 → 音频：WAV / MP3 / FLAC / OGG 互转，自动识别并保留声道、采样率
- 质量/压缩可选：MP3 码率、WAV 采样率、FLAC 压缩级别、OGG 音质
- 支持一次拖入多个文件批量转换
- 纯本机运行，不联网；配置只保存在本目录

## 启动

1. 双击 `MIDI转换器.pyw`（推荐，不会弹出黑色命令行窗口）
2. 或者双击 `启动.bat`

需要 Windows 10/11、Python 3.8 及以上，并安装依赖：

```
pip install numpy soundfile lameenc
```

也可以直接双击 `安装依赖.bat`。

想放到桌面 / 任务栏：右键 `MIDI转换器.pyw` → 发送到 → 桌面快捷方式；
再右键快捷方式 → 固定到任务栏即可。

## 使用

1. 把 MIDI 或音频文件拖到窗口中间的虚线框里（也可以点虚线框选择文件，或按 `Enter`）
2. 选输出格式和质量
3. 点「转换」（或再按一次 `Enter`）

转换完成后，文件默认保存在**原文件所在目录**，文件名为原文件名加新扩展名。
如果同名文件已存在，会自动加 ` (1)`、` (2)`；源文件和目标格式相同时会生成 `xxx (转换).wav`，不会覆盖原文件。

| 操作 | 效果 |
| --- | --- |
| 单击虚线框 | 选择文件 |
| 双击虚线框 | 已有文件时直接开始转换，否则选择文件 |
| 单击底部状态行 | 在资源管理器中选中刚生成的文件 |
| 右键底部状态行 | 查看输出路径 / 失败原因 |

### 支持的输入

- MIDI：`.mid`、`.midi`、`.rmi`、`.kar`
- 音频：`.wav`、`.mp3`、`.flac`、`.ogg`、`.oga`、`.aif`、`.aiff`、`.au`、`.w64`、`.caf`、`.voc`、`.snd`
  （具体能读哪些由 libsndfile 决定；损坏或加密的文件会报错）
- 也可以把文件夹拖进来，程序只扫描该文件夹第一层里的支持文件

### 输出格式与质量

| 格式 | 质量选项 | 说明 |
| --- | --- | --- |
| MP3 | 128 / 192 / 320 kbps | 默认 192 kbps，体积和音质比较均衡 |
| WAV | 22.05 / 44.1 / 48 kHz | 16 位 PCM，不压缩 |
| FLAC | 快速 / 标准 / 最大压缩 | 无损；选项只影响压缩速度和文件大小，不影响音质 |
| OGG | 低 / 标准 / 高 | Vorbis 有损压缩，高音质档体积也比较小 |

MIDI 合成和音频转码都在后台线程里做，界面不会卡住；处理大文件时底部会显示百分比。

## MIDI 音色说明

MIDI 本身只有音符，没有声音。本工具读取 Windows 自带的 `C:\Windows\System32\drivers\gm.dls`
（General MIDI 波表音色库）离线渲染，所以听起来就是 Windows 经典的 GM 音色。

- 换电脑后音色由那台机器的 `gm.dls` 决定；Windows 10/11 默认都有
- 不支持 SoundFont（.sf2）或 FluidSynth，也不支持 VST 音源
- MIDI 里的通道 10 按鼓组处理；支持延音踏板、弯音、音色切换、音量、声像
- 不支持 MIDI 的歌词、视频、歌词同步等附加内容

## 限制

- 不支持 M4A / AAC / WMA 等需要额外编解码器的格式（没有内置 ffmpeg）
- 单个 MIDI 最长 30 分钟
- 多声道（超过 2 声道）的音频会先合并成单声道再转换
- 有损格式之间互转会再压缩一次，音质会有损失，建议尽量从 WAV / FLAC 转出

## 配置文件

位置：本目录下的 `config.json`（第一次运行自动生成）。

```json
{
  "version": 1,
  "settings": {
    "format": "MP3",
    "quality": {
      "MP3": "192",
      "WAV": "44100",
      "FLAC": "0.6",
      "OGG": "0.5"
    },
    "window_geometry": "",
    "last_dir": ""
  }
}
```

- `format`：上次使用的输出格式
- `quality`：每种格式各自记住的质量档
- `window_geometry` / `last_dir`：窗口位置、上次选文件的目录
- 配置写坏时会备份成 `config.json.broken`，再生成默认配置

## 备份 / 迁移

整个 `MIDI转换器` 目录拷到新电脑即可（新电脑需要装依赖，并且有 `gm.dls`）。

## 卸载

直接删掉这个目录即可；不会写注册表，也不会留下其它文件。
