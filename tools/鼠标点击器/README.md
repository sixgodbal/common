# 鼠标点击器

连点、录制、宏回放三合一的小工具。把重复的鼠标点击、键盘按键、移动轨迹和等待时间录下来，之后按一个键就能原样重放。

- 连点器：自定义间隔、鼠标键、单击/双击、固定坐标，F6 一键开关
- 鼠标录制：记录鼠标轨迹、点击、滚轮和键盘输入，自动保存成宏
- 宏库：F8 回放、循环/变速、逐条分解事件、合并宏、生成独立 Python 脚本
- 全部数据保存在本目录，不联网、不写注册表
- 界面用 Python 自带的 tkinter，输入模拟和全局快捷键用 pynput

## 启动

1. 双击 `鼠标点击器.pyw`（推荐，不会出现黑色命令行窗口）
2. 或者双击 `启动.bat`

需要本机有 Python 3.8 及以上版本，并且安装依赖：

```
pip install pynput
```

也可以直接双击 `安装依赖.bat`。本机已经装过 pynput 的话，跳过这一步。

想放到桌面 / 任务栏：右键 `鼠标点击器.pyw` → 发送到 → 桌面快捷方式；再右键快捷方式 → 固定到任务栏即可。

## 三个功能

### 1. 连点器

| 设置 | 说明 |
| --- | --- |
| 点击间隔 | 两次点击之间等待的毫秒数，最小 1 毫秒；预设 10 / 50 / 100 / 200 / 500 / 1000 |
| 鼠标按键 | 左键 / 右键 / 中键 |
| 点击方式 | 单击 / 双击（双击是两次快速点击，间隔 60 毫秒） |
| 点击位置 | 跟随鼠标：点当前指针所在位置；固定坐标：每次都点 (X, Y) |
| 重复次数 | 无限，或指定次数后自动停止 |

- 按 `F6` 开始 / 停止，鼠标在哪就点哪，适合一边看屏幕一边连点。
- 点界面上的「开始连点」时，如果当前是「跟随鼠标」，会先倒计时 2 秒并把本窗口最小化，留时间把鼠标移到目标上；固定坐标是 1 秒。这个倒计时可以在「设置」里关掉。
- 固定坐标可以直接输入，也可以点「拾取…」：工具会最小化，3 秒后自动记录鼠标位置；点「取当前」则立即填入当前坐标。
- 运行中随时按 `F9` 停止。停止后窗口会自动恢复。

### 2. 录制（鼠标录制）

按 `F7`（或点「开始录制」）→ 倒计时 → 开始记录。完成操作后再按 `F7` 停止，录制内容会自动保存成一个宏，出现在「宏库」里。

- 可选记录：鼠标轨迹、点击与滚轮、键盘按键；轨迹默认每移动 4 像素采样一次，数值越小越顺滑、文件越大。
- 默认录制时最小化本窗口；从本窗口开始的录制，结束后会自动恢复；在其它程序里按 `F7` 开始的录制会保持最小化，结果去「宏库」查看。也可以用「录制时最小化本窗口」关掉自动最小化。
- 停止方式：`F7`，或 `F9`（F9 也会停止并保存），或恢复窗口后点「停止录制」。
- 录制期间 `F6` / `F8` 不会触发连点或回放；工具自己的快捷键也不会被写进宏。
- 点击工具上的「停止录制」按钮时，这一次点击会自动从录制里剔除。
- 在「宏库」里选中一个宏，点「追加录制」，可以把新录的一段接在已有宏后面。

### 3. 宏库

左侧是全部宏，右侧是详情和事件分解。

- 选中宏后按 `F8`，或点「播放」，回放当前宏。
- 可以设置循环次数（1～100000）或无限循环、回放速度（0.25x～4x）；按 `F9` 随时停止。
- 事件分解：每条移动、点击、滚轮、按键都列出来，包含时间、间隔、动作。
  - 双击事件或点「编辑事件…」，可以改坐标、鼠标键、按下/松开、按键、滚动量、距上一个事件的间隔。
  - 「删除选中」只删除这一条动作，其它动作的时间轴不变（相当于那段时间什么都不做）。
  - 「提前 0.1s / 延后 0.1s」会把选中的事件以及它后面的事件整体前移/后移，用来压缩或增加等待。
- 「合并宏…」可以把另一个宏追加到当前宏末尾（两段之间可设置等待毫秒数），用来重新组合多段录制。
- 「导出脚本」生成一个独立的 Python 回放脚本，不依赖本工具，只需要 pynput：
  ```
  pip install pynput
  python 宏名字.py
  ```
  脚本顶部有 `SPEED`、`LOOPS`、`GAP` 三个参数可以改；按 `Ctrl+C` 停止。
- 「导出 JSON」备份单个宏；「导入」可以把宏文件放到另一台电脑上继续用。
- 重命名、删除都在顶部工具栏。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `F6` | 开始 / 停止连点 |
| `F7` | 开始 / 停止录制 |
| `F8` | 回放当前选中的宏 |
| `F9` | 紧急停止：连点、录制、回放、倒计时都立即停止（固定，不能改） |
| `Esc` | 在修改快捷键窗口里取消 |

`F6` / `F7` / `F8` 可以在界面里点「修改」换成其它键。为了避免打字时误触，**单键只允许 F1～F24**；如果想用字母/数字，必须带 Ctrl / Alt / Shift / Win，例如 `Ctrl+Alt+R`。尽量用功能键，避免占用 `Ctrl+A` 这类常用组合。

## 推荐流程

1. 先在「连点器」里设好间隔和位置，按 `F6` 试一段，`F9` 停止。
2. 要录复杂动作就切到「录制」，按 `F7` 做一遍，再按 `F7` 停止。
3. 到「宏库」选中刚录的宏，按 `F8` 回放；不合适就双击事件改一改，或者重新录一段「追加录制」。
4. 需要循环就设置循环次数或勾选「无限」，需要慢一点就调低速度。

## 数据和文件

```
鼠标点击器/
├─ 鼠标点击器.pyw     主程序
├─ 启动.bat           启动脚本
├─ 安装依赖.bat       安装 pynput
├─ icon.ico           窗口图标
├─ config.json        设置（删掉后下一次运行会自动生成）
├─ macros/            每个宏一个 JSON
└─ logs/error.log     出错时的日志（自动生成）
```

宏文件是普通 JSON，一个事件长这样：

```json
{
  "t": 1250.5,
  "type": "button",
  "x": 640,
  "y": 360,
  "button": "left",
  "pressed": true
}
```

`t` 是相对录制开始的毫秒数。`type` 有 `move` / `button` / `scroll` / `key` 四种；`key` 事件会记录 `key`、可选 `vk` 和 `text`，保证回放时按键尽量一致。

备份或换电脑：把整个 `鼠标点击器` 文件夹拷走即可。设置和宏都在里面；路径用的都是本机屏幕坐标，换电脑后建议用「拾取…」重新确认固定坐标。

## 注意事项

- **管理员窗口**：Windows 不允许普通程序向以管理员身份运行的窗口发送输入。需要操作这类窗口时，右键本工具 →「以管理员身份运行」。
- **游戏/安全软件**：部分游戏和反作弊会拦截全局键鼠钩子或模拟输入，这是对方程序的保护机制，与本工具无关。Windows Defender 也可能在首次运行时提示，允许即可。
- **UAC / 锁屏界面**：安全桌面上的按键不会被全局快捷键截获，回放也无法操作 UAC 弹窗。
- **不要同时开两个**本工具，否则两个实例的全局快捷键都会响应。
- 停止回放/录制请按 `F9`；因为回放过程中会模拟按键，`F8` 可能被当作宏的一部分，F9 更可靠。
- 回放停止、宏结束或程序退出时，工具会自动松开所有仍按住的键和鼠标按钮，避免卡住 Ctrl / Shift。
- 录制记录的是键盘的原始按键，不是输入法上屏后的文字。中文输入法的候选词选择可能无法原样回放，建议宏里只录快捷键和英文/数字。
- 鼠标轨迹是屏幕坐标。多显示器、不同缩放比例（DPI）混用时，固定坐标或录制坐标可能有少量偏移，建议先小范围试一次。
- 「回放宏时最小化本窗口」默认开启（从本窗口启动回放时生效），避免宏点到工具自己；如果宏就是要操作本窗口，可以在「设置」里关掉。
- 本工具用全局键鼠钩子和 SendInput，属于正常自动化用途；请只在允许自动化的程序里使用。

## 卸载

直接删掉 `鼠标点击器` 文件夹即可，不会留下注册表项或其它文件。
