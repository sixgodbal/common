## 3. 运行与依赖

- Python 3.8+，只用标准库：`tkinter / json / threading / subprocess / ctypes / tempfile`。
- 标签页模式额外依赖 Windows 自带的 `powershell.exe`（5.1 即可）。
- 标签页硬性要求：Windows 11 22H2，`build >= 22621`（`TAB_MIN_BUILD`，第 490 行）。
  更低版本或 `explorer_tabs.ps1` 缺失时，`open_in_tabs` 自动改为逐个窗口打开，不报错。
- 进程启动时调 `enable_dpi_awareness()`；尺寸用 `ui_scale()` 按 DPI 缩放，字体用「点」单位。

## 4. 配置结构（config.json）

```jsonc
{
  "version": 1,
  "settings": {
    "open_mode": "tabs",          // tabs=一个窗口多标签(默认)  windows=每个文件夹一个窗口
    "open_delay_ms": 60,          // 仅 windows 模式：相邻窗口启动间隔，0=同时
    "minimize_after_open": false, // 打开后最小化主窗口
    "always_on_top": false,       // 主窗口置顶
    "window_geometry": ""         // 关闭时自动写入，如 "1020x720+450+120"
  },
  "groups": [
    {
      "id": "d3eabbd2",           // uuid4 前 8 位，删改/排序都靠它，不要重复
      "name": "项目 A 开发",
      "color": "#2F6FED",         // 卡片左侧色条
      "items": [
        { "id": "9159d2e4", "name": "前端", "path": "D:\\work\\A\\frontend" },
        { "id": "d4487317", "name": "",    "path": "%TEMP%" }   // name 空=自动取文件夹名
      ]
    }
  ]
}
```

路径解析统一走 `resolve_path()`（第 147 行）：

1. 去首尾空白与引号；
2. `expandvars` + `expanduser`（支持 `%USERPROFILE%` 等）；
3. 非绝对路径按 `BASE_DIR` 拼接；
4. `normpath`。

配置读写：

- `default_config()`（202）：首次运行的两组示例。
- `normalize_config()`（231）：**唯一的结构校验入口**。新增字段要在这里补默认值和类型校验。
- `write_config()`（278）：写 `.tmp` 再 `os.replace`，避免半截文件。
- `load_config()`（286）：解析失败 → 备份 `config.json.broken` → 重建默认。
- 保存入口只有 `App.save()`（978）；`ConfigDialog._save`（1758）与 `SettingsDialog._save`（1331）都先改 `app.data` 再调它。

## 6. 核心流程

### 6.1 「打开全部」→ 同窗口标签页（当前默认）

```
GroupCard 打开全部
  → App.open_items(group, items)                       883
      1. resolve_path + os.path.exists 分类 exists / missing
      2. missing 非空：showwarning / askyesno（全部缺失直接 return）
  → App._launch(paths)                                 920
      mode = settings.open_mode
      use_tabs = mode=="tabs" and len(paths)>1 and tabs_supported()
  → [后台线程] open_in_tabs(paths)                     549
      1. explorer.exe /n "第一个路径"  → EnumWindows 差集找到新窗口 hwnd（8s 超时）
      2. 路径列表写 UTF-8 临时 JSON
      3. powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden
            -File explorer_tabs.ps1 -Hwnd <hwnd> -PathsFile <json>
      4. 解析 stdout 最后一行 JSON {opened,total,errors,ms_per_tab}
      5. 错误码经 TAB_ERROR_TEXT 翻成中文
  → App._launch_done(count, errors, tabs=True)         950
      状态栏「已在同一窗口的 n 个标签页中打开」；有错误则弹窗
```

`explorer_tabs.ps1` 的协议：

- 入参：`-Hwnd <十进制窗口句柄>`、`-PathsFile <UTF-8 JSON 数组文件>`（第一个路径已由 Python 打开，脚本从第 2 个开始）。
- 出参：单行 JSON，`opened` 为成功数，`errors` 为英文错误码，`ms_per_tab` 为平均耗时。
- 错误码 → 中文映射表：`TAB_ERROR_TEXT`（509）。新增错误码时两处一起改。

脚本内部每个标签的固定流程：

1. `Get-Win`：`AutomationElement.FromHandle(hwnd)` 拿窗口元素（失败重试）。
2. `Get-TabItems`：在窗口后代里找 `ControlType=TabItem` 且 `ClassName=ListViewItem` 且相对窗口顶部 < 90px 的元素 —— **这是真正的标签栏**。
   （主页里的「最近使用的文件/收藏夹/已共享」也是 TabItem，但 ClassName 是 `Microsoft.UI.Xaml.Controls.NavigationViewItem`、位置在下方，必须排除。）
3. 找到 AutomationId=`AddButton` 的「新建标签页」按钮，`InvokePattern.Invoke()` —— 后台点击，不抢焦点。
4. 轮询 `Shell.Application.Windows()` 中 `HWND` 等于目标窗口、且 `LocationURL` 为空的项：这就是刚建的空标签（Home）。
5. 对该项 `Navigate2(path)`，轮询 `LocationName` 或当前选中标签名 == 目标文件夹名，最多重试 2 次。
6. 成功 `opened++`，失败记录 `navigation timeout` 并继续下一个。

### 6.2 打开单个文件夹

`GroupCard._make_chip` 绑定左键 → `App.open_items(group, [item])` → `_launch`。
只有 1 个路径时不走标签页分支，`open_path()`（168）直接 `os.startfile`（macOS/Linux 用 `open`/`xdg-open`）。

### 6.3 缺失路径判定

- 渲染时：`GroupCard.__init__` 统计 `missing`，写进卡片 subtitle；芯片变红。
- 打开时：`open_items` 再判一次（配置可能刚被手改），弹窗列出前 10 条，问是否继续打开其余。
- 全部缺失：只提示，不打开任何窗口。
- 单个文件夹右键「在资源管理器中显示」：`reveal_path`（177）用 `explorer /select,`。

### 6.4 配置编辑（ConfigDialog）

- 打开时 `self.data = copy.deepcopy(app.data)`，所有改动只动副本；`self.group_id` 记录当前分组（用 id 而不是下标）。
- 左侧 Listbox 顺序即分组顺序；右侧 Treeview 的 `iid` 就是 item 的 `id`，别用行号定位。
- 名称输入框用 `trace_add` 实时写副本，并用 `self._loading` 抑制刷新时的回环。
- 颜色下拉：`COLOR_NAMES`(中文) ↔ `PALETTE`(hex)，转换函数 `color_name` / `color_hex`。
- `_save`：空名字补「未命名分组」→ `app.data = self.data` → `app.save()` → `apply_settings()` → `rebuild()`。
- 删除分组/条目只改副本，点「保存」才落盘（删除分组有确认框）。

### 6.5 设置（SettingsDialog）

`open_mode` 用两个 Radiobutton 写 `self.mode_var`；`_save` 里再次白名单校验（只允许 `tabs`/`windows`），然后 `app.save()`。
标签页不可用时（系统版本低）单选仍显示，但实际会走多窗口；提示文案由 `tabs_supported()` 决定。

## 8. Win11 标签页：实现细节与踩过的坑

### 8.1 为什么不用模拟按键

最初版本：`Ctrl+T` 新建标签 → `Ctrl+L` 聚焦地址栏 → 剪贴板粘贴路径 → `Enter`。
实测问题：**只要期间有别的窗口抢到前台，整串按键会打进那个窗口**（测试时真的打进了浏览器/Anytone 等程序），而且 `Ctrl+T` 是否生效只能靠窗口标题猜测。已全部删除，不要再改回去。

### 8.2 UIA 结构（本机 Win11 22631 实测）

- 新建标签按钮：`ControlType=Button`，`AutomationId=AddButton`，Name=「添加新标签页」，支持 `InvokePattern`。
- 地址栏：`ControlType=Edit`，`AutomationId=TextBox`，支持 `ValuePattern`；**同窗口第二个 Edit 是搜索框，取第一个**。
- 标签栏项：`ControlType=TabItem`，`ClassName=ListViewItem`，相对窗口顶部 < 90px。
- 主页的「最近使用的文件 / 收藏夹 / 已共享」也报 `TabItem`，但 `ClassName=Microsoft.UI.Xaml.Controls.NavigationViewItem`，`relTop≈560`，**必须按 ClassName 过滤**，否则标签数会多算。

### 8.3 Shell.Application 与「每个标签一个对象」

`Shell.Application.Windows()` 里，同一个 `HWND` 会按标签出现多条：

- `LocationURL` 非空的是已导航标签；
- 刚建好、还在主页的标签 `LocationURL` 为空、`LocationName` 为「主文件夹」。

`Navigate2()` **作用于你调用的那个对象**（哪条记录），不是窗口的当前标签。
所以正确姿势：建标签 → 找「空 LocationURL 的最新一条」→ 对它 `Navigate2`。
（早期错误做法：拿窗口第一条记录 `Navigate2`，结果一直导航第一个标签，主页标签越积越多。）

### 8.4 编码

- `explorer_tabs.ps1` **必须保持纯 ASCII**：Write 工具写出的 UTF-8 无 BOM 文件，Windows PowerShell 5.1 会按 ANSI 解析中文，直接语法错误。要写中文就先存成 UTF-8 with BOM，或干脆不用中文。
- 路径通过 UTF-8 临时 JSON 传给 PS（`[IO.File]::ReadAllText(..., UTF8)`），避免命令行引号/中文转义问题。
- Python 读 PS 输出固定 `encoding="utf-8"`；PS 只输出 ASCII 的 JSON 与错误码。

### 8.5 失败降级

| 情况 | 行为 |
| --- | --- |
| 系统 < 22621 或脚本缺失 | 逐个窗口打开（不提示） |
| PS 起不来 / 输出不可解析 | 只打开第一个，弹窗说明，建议切 windows 模式 |
| 中途 `AddButton` 找不到 / 标签没建出来 | 停止后续标签，已建的保留 |
| 某个标签导航超时 | 该项记 `navigation timeout`，其余继续；该标签会停在主页 |
| 找不到新窗口 | 其余路径改为逐个窗口打开，并说明 |

## 10. 常见改动指引

### 加一个设置项（以 `open_delay_ms` 为例，共 4 处）

1. `DEFAULT_SETTINGS`（51）加默认值；
2. `normalize_config`（231）加类型/范围校验；
3. `SettingsDialog.__init__`（1223）加控件 + `_save`（1331）写回；
4. 使用处读 `self.data["settings"]["xxx"]`（如 `_launch` 920）；
5. `README.md` 的配置说明补一句。

### 加一种打开方式

1. `normalize_config` 的白名单加值（`open_mode` 现在是 `tabs`/`windows`）；
2. `SettingsDialog` 加 Radiobutton；

4. 后台工作放线程里，**不要在工作线程直接碰 tkinter**，用 `self.after(0, ...)` 回主线程。

## 11. 已知限制 / 可做的事

- 标签页模式依赖 UIA 文案与结构，Windows 大版本更新后可能变（按钮名/AutomationId 一般稳定，ClassName 可能变）；出问题时先跑 `dev\test_tabs.py` 定位是「建标签」还是「导航」失败。
- 同时只能对一个分组执行「打开全部」；重复点击会再开一个新窗口（不会复用旧窗口）。
- 不支持「把单个文件夹追加到已有窗口的标签」——当前单个文件夹始终新开窗口，需要的话在 `_launch` 里扩展。
- 不支持开机自启 / 全局热键（没做，避免注册表与常驻进程）。
- 配置没有版本迁移逻辑，`version` 字段目前恒为 1；若将来改结构，在 `normalize_config` 里做兼容。
- 批量添加只做「同分组内路径去重」，不做路径有效性校验（列表里会以红色标出无效项）。
