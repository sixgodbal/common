# 快速打开文件夹

把「项目 A 要同时打开的 6 个文件夹」做成一个按钮，点一下全部打开。
项目 B 是另一张卡片，互不干扰。

- 纯 Python 标准库（tkinter），不需要安装任何依赖
- 点「打开全部」时，默认把一组文件夹开在**同一个资源管理器窗口的 n 个标签页**里
- 配置保存在本地 `config.json`，界面里可视化编辑，也可以手动改文件
- 不联网、不写注册表

## 启动

1. 双击 `快速打开.pyw`（推荐，不会弹出黑色命令行窗口）
2. 或者双击 `启动.bat`

需要本机有 Python 3.8 及以上版本（安装时勾选 tcl/tk，默认就有）。
标签页模式需要 Windows 11（22H2 / Build 22621 及以上）；其它系统会自动按「每个文件夹单独一个窗口」打开。

想放到桌面 / 任务栏：右键 `快速打开.pyw` → 发送到 → 桌面快捷方式；
再右键快捷方式 → 固定到任务栏即可。

## 使用

主界面里每张卡片就是一个「功能分组」，卡片上的文件夹按钮点一下就打开：

| 操作 | 效果 |
| --- | --- |
| 卡片右上角「打开全部」 | 一个窗口、n 个标签页，每个标签对应一个文件夹（可在设置里改成多窗口） |
| 点某个文件夹按钮 | 只打开这一个文件夹（单独一个窗口） |
| 右键文件夹按钮 | 打开 / 在资源管理器中显示 / 复制路径 / 编辑该分组 |
| 顶部「筛选」框 | 按分组名、文件夹名或路径过滤（Ctrl+F 聚焦，Esc 清空） |
| 「管理配置」 | 增删改分组、排序、增删改文件夹、批量添加路径 |
| 「设置」 | 打开方式（标签页 / 多窗口）、打开间隔、打开后最小化、窗口置顶 |

快捷键：`F5` 重新载入配置，`Ctrl+N` 新建分组，`Ctrl+E` 打开管理配置，`Ctrl+S` 保存（管理配置窗口内）。

路径不存在时会提示出来，并问你是否继续打开其余存在的文件夹；界面上这类按钮是红色的，卡片标题旁也会显示「N 个路径不存在」。

### 标签页模式是怎么做的

`explorer_tabs.ps1` 用 Windows UI Automation 在后台点资源管理器的「新建标签页」按钮，
再用 Shell COM 把新标签导航到目标文件夹。全程**不模拟键盘、不占用剪贴板、不抢焦点**，
标签页在后台逐个建好，速度约 0.8 秒/个。

如果中途出错（例如资源管理器被关掉、标签页功能被系统策略禁用），会弹窗说明原因，
已经建好的标签页不会丢；可以到「设置」里切换成「每个文件夹单独一个窗口」。

## 配置文件

位置：本目录下的 `config.json`（第一次运行自动生成）。

```json
{
  "version": 1,
  "settings": {
    "open_mode": "tabs",
    "open_delay_ms": 60,
    "minimize_after_open": false,
    "always_on_top": false,
    "window_geometry": ""
  },
  "groups": [
    {
      "id": "d3eabbd2",
      "name": "项目 A 开发",
      "color": "#2F6FED",
      "items": [
        { "id": "9159d2e4", "name": "前端", "path": "D:\\work\\projectA\\frontend" },
        { "id": "d4487317", "name": "后端", "path": "D:\\work\\projectA\\backend" },
        { "id": "0e5e89c6", "name": "日志", "path": "%LOCALAPPDATA%\\projectA\\logs" }
      ]
    }
  ]
}
```

说明：

- `groups`：一张卡片 = 一个分组，靠 `id` 区分，不要重复。
- `items`：分组里的文件夹。`name` 是按钮上显示的文字，留空时自动取文件夹名。
- `path` 支持三种写法：
  - 绝对路径：`D:\work\projectA`
  - 环境变量：`%USERPROFILE%\Desktop`、`%TEMP%`、`%LOCALAPPDATA%\...`
  - 相对路径：`logs`、`..\shared`（以本工具所在目录为基准）
- `color`：卡片的左侧色条，用 `#RRGGBB`，也可以在界面里选预设颜色。
- `settings.open_mode`：`tabs` = 同一窗口标签页（默认，仅 Win11），`windows` = 每个文件夹一个窗口。
- `settings.open_delay_ms`：**仅多窗口模式**使用，每打开一个文件夹之间等待的毫秒数。`0` 表示同时打开（最快）；如果系统偶尔漏开窗口，可以调到 `60`～`150`。
- 手动改完 `config.json` 后按 `F5` 重新载入，或重启工具。

> 编辑配置时如果文件格式写坏了，工具会把原文件备份成 `config.json.broken`，然后生成一份新的默认配置。

## 备份 / 迁移

整个 `快速打开文件夹` 目录拷到新电脑就能用（路径不同的话改 `config.json` 即可，建议用环境变量或相对路径写）。

## 卸载

直接删掉这个目录即可，不会留下其它东西。
